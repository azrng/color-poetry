# 引用资料：传统工艺核查

## 蓝染与靛青

- 蓝草（蓼蓝、菘蓝、马蓝等）叶含吲哚酚类化合物，植株本身绿色，不含现成蓝色素
- 制靛：叶经发酵、打靛后，靛蓝素与石灰的钙离子结合沉淀，成「靛泥」
- 染色：靛蓝不溶于水，须在碱性还原液中转为可溶隐色体（靛白 / leucoindigo）；织物出缸呈黄绿色，接触空气数分钟氧化回靛蓝，肉眼可见由绿转蓝
- 浸染次数越多颜色越深，可从月白之蓝到近乎墨色的浓青
- 化学上「靛青」即靛蓝（indigo）的别名

### 与靛青.md 的对照（2026-10-19）

- 一色一源「叶子绿油油、一点不蓝」「入缸发酵、沉淀成靛泥」「出缸黄绿色，见风几分钟变蓝」与上述机理一致
- 一色一物「布出缸时偏绿，遇到空气才渐渐转蓝」「浸染一遍，颜色便加深一遍」与上述机理一致

## 蓝印花布

- 工艺：黄豆粉与石灰调成防染浆 → 透过镂花版刮浆于白布 → 入靛缸反复浸染 → 刮去灰浆，刮浆处留白显蓝底白花
- 历史：明清时期盛行于江浙一带市镇；江苏南通蓝印花布印染技艺列入国家级非物质文化遗产名录

### 与靛青.md 的对照（2026-10-19）

一色一物「以黄豆粉与石灰调成防染浆，透过镂花版刮在白布上，再入靛缸反复浸染」「明清时期，在江浙一带的市镇间盛行」表述准确

## 藕荷色（2026-10-26，藕荷.md 一色一源）

### 名称与色相口径

- 藕荷：浅紫而略带粉红，比浅紫暗；深藕荷更泛紫（人民周刊《中国传统颜色的雅称》）
- 「藕荷」即「藕合」的异写，国语辞典释为「浅紫而微红的颜色」（词典引《诗经三百首》电子辞书条目）
- 藕色与藕荷色是两个颜色：藕色浅灰微红不发紫，藕荷色发紫（探索揭秘网辨析；藕色出处《红楼梦》第四十六回「藕色绫」）

### 服饰史实

- 乾隆「藕荷色纱绣八团彩云蝠花卉金龙纹女单龙袍」：单层藕荷色芝地纱，宫中妃嫔夏季节庆服装；「藕荷色是清代服装最主要的装饰色之一，也称藕色或荷色，康雍乾时期淡雅紫色相最美丽」（澎湃新闻「国采与宫色」清宫旧藏织绣服饰展报道）

### 瓷器史实

- 故宫博物院藏「藕荷地粉彩花鸟纹四足盆、奁」，清光绪，口沿下红彩「大雅斋」楷书款与「天地一家春」篆书款（故宫博物院官网藏品页）
- 大雅斋瓷为慈禧太后专门设计烧制的御用瓷，地釉十二种中「藕荷地」「浅藕荷地」在列，且以粉地、藕荷地、明黄地、蓝地为多（人民网艺术收藏《慈禧御瓷：大雅斋瓷器》）

### 未定源表述（谨慎使用）

- 「新藕切面粉白、煮熟后粉中带紫微灰，藕荷色更像熟藕」：帖子标注为「常见解释」，本轮未检得权威辞书或工艺文献出处；属民间说法口径，不作史实背书
