# 引用资料：写作规范与审查基准

> 供审查 `contents/*.md` 文案质量与结构一致性，不参与站点渲染。

## 系列结构

每篇颜色文章固定三个栏目，均为分开发布的连载：

| 栏目 | 定位 | 配图 |
| --- | --- | --- |
| 一色一诗 | 颜色 × 一首古诗，三张壁纸图解诗意瞬间 | 3 张 |
| 一色一源 | 颜色名 / 原料的来源冷知识 | 1 张 |
| 一色一物 | 颜色落在一件实物（器物 / 织物）上 | 3 张 |

## 栏目内固定骨架（以靛青.md 为基准样本）

1. 开篇：一句「如果…有颜色」式设问或断语，点出颜色与意象
2. 中段：2–3 段展开颜色特质、诗句化用或工艺 / 器物事实
3. 「三张壁纸」段：图一 / 图二 / 图三逐张说明画面内容，与配图一一对应
4. 互动引导：一句向读者提问（选哪张 / 想染什么 / 下一期想看什么颜色）
5. 图片引用
6. 标签行：8 个话题标签，行首 `#` 必须转义为 `\#`，否则 Markdown 渲染歧义

### 各栏目收尾惯例句式

- 一色一物惯用「不是色卡上孤零零的一格/一块」的呼应句 + 「下一期，你想看哪种颜色…」收尾
- 一色一源、一色一诗以提问引导互动收尾

## 审查清单

结构 / 格式：

- [ ] frontmatter 四字段齐全：`name` / `slug`（拼音小写，唯一）/ `hex`（#RRGGBB）/ `order`（全站唯一，左侧列表排序）
- [ ] 三个栏目小节均为 `## 栏目名` + `### 标题` + `### 正文`，标题行在「### 标题」后空一行
- [ ] 标签行行首 `#` 转义为 `\#`，标签数 8 个
- [ ] 图片路径 `images/<slug>/NN-MM.png` 且文件存在

内容：

- [ ] hex、诗词原文、工艺与史实描述有据（核对方法见同目录 `color-values.md`、`poetry.md`、`crafts.md`）
- [ ] 「三张壁纸」段描述与实际配图内容一致
- [ ] 三个栏目内容不重复：同一典故 / 工艺细节只在一个栏目展开，其余栏目不整段复述
- [ ] 允许艺术演绎（如把诗的意境延到天亮），但不得与原文文义冲突
