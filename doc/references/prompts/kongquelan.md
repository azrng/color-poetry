# 孔雀蓝 · 插画提示词

## 一色一诗 · 图一《楚江天开》 → 01-01.png

竖版9:16手机壁纸，中国古典轻水墨×精致国风插画×宋画青绿山水意境。远景为天门山两峰对峙，以淡墨轻皴、青灰微染，山口虚开如门；中景江面以孔雀蓝#0EB0C9为主调，碧水自远处奔流而下，至山前微微回旋，水面以细笔勾出层层水纹，波光清透；近景左下角一叶孤帆缓缓驶向江口，帆面米白微透，船身淡墨简笔，帆影一点暖金，自日边而来。画面左侧崖壁一角以浓墨写就，崖顶一株古松斜出，枝干遒劲。时值正午，天朗气清，日光自右上方柔和洒落，江面浮起细碎光斑。宣纸绢本质感，水墨轻微晕染，工笔细节与写意留白结合，前景清晰、中景柔和、远景淡雅。顶部天空留白约百分之三十五，为手机时间日期预留。右侧竖排行书题写"天门中断楚江开，碧水东流至此回"，墨色深墨，浓淡枯润自然，句末钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写体签章"azrng"，形如古雅私印。整体低饱和、空灵雅致，留白约三分之一。

## 一色一诗 · 图二《孤帆日边》 → 01-02.png

竖版9:16手机壁纸，中国古典轻水墨×精致国风插画，极简构图，宋画留白意境。画面下方三分之一为一横孔雀蓝#0EB0C9的江面，色如釉润，水面仅有两三道极细的墨线波纹，安静无声；江面之上，一叶孤帆居画面中下偏左，帆形小巧，帆面米白微透光，船身以淡墨一笔写就，正逆光向远方行去。画面上方大面积留白为宣纸底色，留白约百分之四十五，空阔渺远；右上方悬一轮极淡的暖金日轮，虚化如水中月，日轮之下，三两只远雁以淡墨点出，一字排开渐远渐淡。时为清晨，天光初醒，江雾未散尽，帆与雁皆安静。宣纸质感，水墨边缘轻微晕染，笔意克制。左侧竖排小楷题写"孤帆一片日边来"，仅此一句，墨色深墨带自然飞白，句旁钤一枚极小朱红篆印。右下角自然融入极小的淡金色手写体签章"azrng"，低调如古私印。整幅以孔雀蓝为魂，愈简愈远，空灵雅致。

## 一色一诗 · 图三《暮江回望》 → 01-03.png

竖版9:16手机壁纸，中国古典轻水墨×精致国风插画，暮色江景，东方诗意情绪延伸。视角自船中回望：近景为画面下方的船头一角，淡墨勾出木船边缘，船头立一位唐人装束的旅人背影，青灰广袖长袍，束发，姿态安静，正回首远望来路，身形仅占画面极小一处；中景江面在暮色中呈现沉静的孔雀蓝#0EB0C9，色泽较正午更深，如绸缎般平滑，水纹极少，几近无声；远景天门山两峰已成青灰剪影，一深一浅，渐渐退向天际，山口之间暮霭微茫。天色向晚，天光自山口处透出最后一抹极淡的暖橘，与孔雀蓝江面形成微妙冷暖呼应，苍茫中见旷达。大面积天空留白，宣纸质感，水墨晕染柔和，前景清晰、远景朦胧。右侧竖排行书题写"两岸青山相对出"，墨色深墨，浓淡枯润自然，句末钤一枚极小朱红篆印。右下角自然融入极小的淡金色手写体签章"azrng"，如古雅私印。整体低饱和、清寂辽阔。
