# 霁青 · 插画提示词

## 一色一诗 · 图一《空山新雨》 → 01-01.png

竖版9:16手机壁纸，中国古典轻水墨与精致国风插画结合，宋画青绿山水意境，整体低饱和、空灵雅致。深秋雨霁之暮，一场秋雨方歇，天空自上而下以霁青色（#63BBD0）由深渐浅自然晕开，散尽的雨云边缘透出淡墨微痕，霁青天幕上悬一轮初升的淡米色圆月，位于画面上三分之一处，月光清透温润，不刺目。中景为层叠松林，松针经雨，墨色浓淡相间，工笔细攒，针叶间凝着细碎雨露，树干以淡墨皴出苍润质感。山脚一泓清泉自白石上蜿蜒流过，溪石以留白与淡墨勾勒，泉水以极细的流畅线条表现，水面映着霁青天光与一点月色。远处山峦以淡墨轻染两三重，隐入霁青暮霭，层次由清晰渐至空濛。松林掩映处一座茅草山居，屋顶覆草、篱笆半掩，窗内透出一点暖黄灯火，以景代情，不出现人物。前景左下为几丛湿润秋草与拳石，笔触细腻。宣纸质感，轻微水墨晕染，留白约35%，顶部20%天空保持简洁，为手机时间日期预留空间。画面右上以清雅行书竖排题写"空山新雨后，天气晚来秋"，自右至左、每列自上而下，墨色深墨带自然浓淡、飞白与枯润变化，句末钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写体签章"azrng"，形如古雅私印，低调融入画面，不作明显Logo与水印。

## 一色一诗 · 图二《月照松间》 → 01-02.png

竖版9:16手机壁纸，中国古典轻水墨与精致国风插画结合，宋画意境，极简构图，主体高度集中。夜色已定，雨后长空如洗，整个画面以霁青色（#63BBD0）为基调，天空自上而下做极细腻的渐变，愈近画面下方愈淡，缓缓融入月白。画面中上方偏右，悬一轮满月，月色呈温润淡金，边缘以极淡光晕自然化开，安静不张扬。自画面右缘伸入一枝苍松，松干虬曲苍劲，以浓淡墨色皴出鳞纹与节疤，一枝松梢斜垂向左下，松针以工笔细攒成簇，针尖凝着未落的雨珠，两三滴正欲坠落，坠向下方大片留白，成为画面唯一的"动势"。墨色松针与霁青夜空形成沉静对比，霁青本身即是主角。画面下方三分之一以淡墨极简地暗示一线远山与浮动的云气，若隐若现，其余皆空，留白约40%。顶部18%为纯粹渐变的霁青天空，干净无物，可安放手机时间与日期。画面左侧以小楷竖排题写"明月松间照，清泉石上流"，自右至左、每列自上而下，墨色深墨，笔画间有自然浓淡与细微飞白，句末钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写体签章"azrng"，形如古雅私印，低调不抢眼。宣纸或绢本质感，轻微水墨晕染，可作锁屏，亦可装裱成一幅东方小品。

## 一色一诗 · 图三《雨霁天明》 → 01-03.png

竖版9:16手机壁纸，中国古典轻水墨与精致国风插画结合，宋画意境。与前两幅不同，此幅将时间推至雨霁之夜的尽头、天光将明未明之际，并采用贴近溪水的低角度平视视角展开。东方天际透出将晓的微光，天空由近地平处的一线淡金微明，向上渐变为清透的霁青色（#63BBD0），一弯下弦残月正缓缓沉向溪面，月影投在水中，被极细的涟漪轻轻揉碎，月影、天光与青色在水面彼此交融，是全画的视觉重心。溪水横贯画面中下部，以留白与淡墨细线表现清澈流势，浅流中卧着几方白石。近景自左右两侧边缘斜出数竿修竹，形成半围合的天然画框，竹叶经夜雨仍带露意，一两滴露珠自叶尖坠向水面，将落未落，竹叶工笔细绘，墨色清润。远处溪岸与竹林隐入未散的晨雾，淡墨轻染，若有若无。整幅画安放在"雨停之后、喧嚣未至"的一刻，比前两幅更安静、更空，情绪是雨后的清寂与将晓的澄明。宣纸纹理，水墨轻晕，前景清晰、中景柔和、远景淡雅，留白约40%，顶部18%为洁净的渐变霁青天空，为手机界面预留空间。画面右上以行楷竖排题写"空山新雨后"五字，自右至左，墨色有自然浓淡、枯润与飞白变化，钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写体签章"azrng"，如古雅私印，低调融入画面。
