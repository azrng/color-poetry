# 霁青 · 插画提示词

## 一色一诗 · 图一《空山新雨》 → 01-01.png

竖版9:16手机壁纸，中国古典轻水墨与精致国风插画结合，宋画青绿山水意境，整体低饱和、空灵雅致。深秋雨霁之暮，一场秋雨方歇，天空自上而下以霁青色（#63BBD0）由深渐浅自然晕开，散尽的雨云边缘透出淡墨微痕，霁青天幕上悬一轮初升的淡米色圆月，位于画面上三分之一处，月光清透温润，不刺目。中景为层叠松林，松针经雨，墨色浓淡相间，工笔细攒，针叶间凝着细碎雨露，树干以淡墨皴出苍润质感。山脚一泓清泉自白石上蜿蜒流过，溪石以留白与淡墨勾勒，泉水以极细的流畅线条表现，水面映着霁青天光与一点月色。远处山峦以淡墨轻染两三重，隐入霁青暮霭，层次由清晰渐至空濛。松林掩映处一座茅草山居，屋顶覆草、篱笆半掩，窗内透出一点暖黄灯火，以景代情，不出现人物。前景左下为几丛湿润秋草与拳石，笔触细腻。宣纸质感，轻微水墨晕染，留白约35%，顶部20%天空保持简洁，为手机时间日期预留空间。画面右上以清雅行书竖排题写"空山新雨后，天气晚来秋"，自右至左、每列自上而下，墨色深墨带自然浓淡、飞白与枯润变化，句末钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写体签章"azrng"，形如古雅私印，低调融入画面，不作明显Logo与水印。

## 一色一诗 · 图二《月照松间》 → 01-02.png

竖版9:16手机壁纸，中国古典轻水墨与精致国风插画结合，宋画意境，极简构图，主体高度集中。夜色已定，雨后长空如洗，整个画面以霁青色（#63BBD0）为基调，天空自上而下做极细腻的渐变，愈近画面下方愈淡，缓缓融入月白。画面中上方偏右，悬一轮满月，月色呈温润淡金，边缘以极淡光晕自然化开，安静不张扬。自画面右缘伸入一枝苍松，松干虬曲苍劲，以浓淡墨色皴出鳞纹与节疤，一枝松梢斜垂向左下，松针以工笔细攒成簇，针尖凝着未落的雨珠，两三滴正欲坠落，坠向下方大片留白，成为画面唯一的"动势"。墨色松针与霁青夜空形成沉静对比，霁青本身即是主角。画面下方三分之一以淡墨极简地暗示一线远山与浮动的云气，若隐若现，其余皆空，留白约40%。顶部18%为纯粹渐变的霁青天空，干净无物，可安放手机时间与日期。画面左侧以小楷竖排题写"明月松间照，清泉石上流"，自右至左、每列自上而下，墨色深墨，笔画间有自然浓淡与细微飞白，句末钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写体签章"azrng"，形如古雅私印，低调不抢眼。宣纸或绢本质感，轻微水墨晕染，可作锁屏，亦可装裱成一幅东方小品。

## 一色一诗 · 图三《雨霁天明》 → 01-03.png

竖版9:16手机壁纸，中国古典轻水墨与精致国风插画结合，宋画意境。与前两幅不同，此幅将时间推至雨霁之夜的尽头、天光将明未明之际，并采用贴近溪水的低角度平视视角展开。东方天际透出将晓的微光，天空由近地平处的一线淡金微明，向上渐变为清透的霁青色（#63BBD0），一弯下弦残月正缓缓沉向溪面，月影投在水中，被极细的涟漪轻轻揉碎，月影、天光与青色在水面彼此交融，是全画的视觉重心。溪水横贯画面中下部，以留白与淡墨细线表现清澈流势，浅流中卧着几方白石。近景自左右两侧边缘斜出数竿修竹，形成半围合的天然画框，竹叶经夜雨仍带露意，一两滴露珠自叶尖坠向水面，将落未落，竹叶工笔细绘，墨色清润。远处溪岸与竹林隐入未散的晨雾，淡墨轻染，若有若无。整幅画安放在"雨停之后、喧嚣未至"的一刻，比前两幅更安静、更空，情绪是雨后的清寂与将晓的澄明。宣纸纹理，水墨轻晕，前景清晰、中景柔和、远景淡雅，留白约40%，顶部18%为洁净的渐变霁青天空，为手机界面预留空间。画面右上以行楷竖排题写"空山新雨后"五字，自右至左，墨色有自然浓淡、枯润与飞白变化，钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写体签章"azrng"，如古雅私印，低调融入画面。

## 一色一源 · 六格册页《雨洗过的青》 → 02-01.png

最终整图提示词：一张竖版3:4宣纸设色插画，中国古典博物小册风格，宋画小品与工笔淡彩结合，主题是中国传统色"霁青"（色值#63BBD0，雨后初晴、干净清透的天青色）。整幅画面如一册散页装裱的古画册，六个小场景以流动的云气纹、淡墨远山与蜿蜒水痕自然连接，不做现代漫画格子，四周保留大片米白留白，宣纸与绢本肌理清晰。

顶部场景：山中雨霁，乌云从画面上角退散，云缝间露出大片霁青色天空，山色被雨水洗得清亮，屋檐滴水落入石缸，小童推开木窗仰头看天。第二场景：书斋内文人提笔在宣纸上写"霁"字，雨字头醒目，窗外天色透出霁青。第三场景：冬日城头，披裘诗人远望雪后终南山，山巅林梢泛着清冷天光，城中炊烟细细。第四场景：雨后夜晚庭院，月出云开，宽袍君子负手立于湿石阶前，神色舒朗坦荡，天空呈霁青与月白之间的清色。第五场景：窑口前匠人双手捧一件深蓝霁蓝釉瓷瓶，举向门外天光比对颜色，小徒弟踮脚张望，窑内透出微红火光。底部场景：晴空全开，一只飞鸟掠过辽阔的霁青天空，小童仍趴在窗边，衣角被风吹起，远山淡墨渐隐于留白。

整体低饱和，米白、淡墨、浅灰打底，霁青色克制地出现在天空、云隙、瓷器釉色高光与个别衣饰细节处，多次呼应但不铺满画面。人物小巧生动，动作细腻，工笔细节与写意笔触结合，水墨负责古意，霁青负责记忆点。各场景旁点缀少量竖排古风小字，如"霁""林表明霁色""光风霁月"，右下角融入一枚极小的淡金色手写体签章"azrng"，形如古雅私印，与纸面自然融合，不做明显水印。

第一格《雨停了》：山中一场雨刚歇，乌云正从画面上角退散，云缝间露出一大片霁青色天空；山色被雨水洗得发亮，屋檐还在滴水，滴入窗下石缸。一位小童推开木窗，探出半个身子仰头看天。配文：一场雨刚走，天空交出的第一张色卡，就叫霁青。

第二格《霁字密码》：书斋内，文人立于案前提笔，宣纸上写着一个大大的"霁"字，雨字头格外醒目；他微微歪头端详，窗外天色正透出霁青，一笔淡青从窗外悄悄映进纸面。配文："霁"就是雨停天晴——霁青，是被雨认真洗过的那种青。

第三格《诗里初霁》：冬日傍晚，披裘诗人立于城头，远望终南山；雪后初晴，山巅林梢泛着一层清冷的天光，城中暮色渐起，炊烟细细。配文：祖咏写"林表明霁色"——雪后初晴的天光，唐人早就收进了诗里。

第四格《光风霁月》：雨后夜晚庭院，月亮从散开的云层里出来，月光洒在湿漉漉的石阶上；一位宽袍君子负手立于庭中，神色坦荡舒朗，天空是霁青与月白之间的清色。配文：古人夸人也用天气："光风霁月"，就是像雨后天空一样坦荡清爽。

第五格《窑火追天》：窑口前，匠人双手捧着一件刚出窑的深蓝霁蓝釉瓷瓶，高高举向门外的天光比对颜色，神情专注；小徒弟踮脚张望，窑口深处透出微红火光。配文：常见说法里，匠人用钴料追天色烧出霁蓝釉，把天空留在了瓷上。

第六格《抬头见青》：回到开篇的窗口，天已全晴，整片霁青天空辽阔干净，一只飞鸟掠过；小童仍趴在窗边，衣角被风吹起，远山淡墨渐渐隐入留白。配文：下次雨停别急着收伞，抬头——那片青，古人替你先看了千年。

## 一色一物 · 图一《案头晴空》 → 03-01.png

中国古典轻水墨×精致国风插画×博物馆静物美学，竖版4:5构图，宣纸绢本质感底色，米白微泛暖意。画面中下部，一件元代风格的霁蓝釉梅瓶端立于深色老木案上：小口、短颈、丰肩、肩以下渐收，造型饱满端庄。通体施霁青色高温釉，釉色以雨后晴空的青蓝（主调参考#63BBD0）为魂，釉面匀净温润、微微失透，隐见橘皮细纹；肩至腹部以留白堆塑技法浮现一条游龙，龙身素白，在青釉间若隐若现，青白相映。木案一角置素色小香炉，青烟一缕极淡；另一侧斜放半卷线装古籍与一枝疏影花枝，皆作陪衬，不抢主体。顶部保留大面积留白，如天光初霁。柔和天光自左上方洒落，瓶肩高光温润不刺眼。整体色彩克制：米白、宣纸色、淡墨、深木色为底，霁青是唯一主角。画面右上方以清雅小楷竖排题"霁青"二字，下配小字"元·霁蓝釉梅瓶"；右下角融入极小淡金色手写体签章"azrng"，形如古雅私印，旁缀一枚极小朱红篆刻小印。宋画小品气质，无任何现代元素。

## 一色一物 · 图二《一色千层》 → 03-02.png

中国古典轻水墨×精致国风插画，竖版4:5，绢本设色质感。极致局部特写构图：截取霁蓝釉梅瓶肩腹一段，微微斜置，占画面主体约三分之二，重点呈现霁青釉色的层次与质感。釉面近观如雨后初晴的晴空，青中透蓝、蓝中含青（主调参考#63BBD0），受光处泛起温润的亮青色，暗部则沉入接近靛蓝的深海色，同一釉色在光线中呈现浓淡、深浅、冷暖的丰富渐变；失透釉面上有细密橘皮纹与极细开片，如岁月留痕。肩部白色堆塑游龙的鳞爪边缘，釉水堆积处色深、流动处色亮，白色龙身在青釉间如浮云破空。背景留出大片绢本米白，仅以淡墨晕染一线瓶身轮廓的余韵。天光斜入，在釉面形成一条柔和高光带，可见釉层厚度的微妙变化。画面左侧以小楷竖排一句"青中含蓝，温润如雨后初晴"，字迹清雅细润。右下角极小淡金手写签章"azrng"，配一枚极小朱红篆印。整体如宋画局部，静谧克制，禁止现代纯色色块与商业摄影感。

## 一色一物 · 图三《天色入瓶》 → 03-03.png

中国古典水墨插画风×古代生活美学，竖版4:5，绢本设色质感。雨刚停的古代文人书斋一隅：窗外芭蕉与远山被雨水洗得清润，天空透出雨后初晴的青蓝（与主色#63BBD0呼应），几缕淡云轻扫天际。窗内深色木条案上，那只霁蓝釉梅瓶安静立于案头，釉色与窗外晴空遥遥相映，一内一外，两片"霁色"互为对答。案上另置笔架、线装书与一只素瓷小盏，皆简素低调。一位着素色襕衫的古代文人侧立于窗畔，仅作环境点缀，比例小、不见正脸，正凭窗望天，衣纹以淡墨简笔勾出。室内光线是雨后天光，柔和清亮，瓶身青釉映着天色，仿佛盛着一小片晴空。整幅色彩克制：米白、淡墨、木色、蕉绿为底，霁青色是唯一鲜明的主角。画面右上以小楷竖排题"一色入瓷，便有了雨后的天空"；右下角极小淡金色手写体签章"azrng"，配一枚极小朱红篆刻小印，低调自然。宋画小品气质，静谧有呼吸感，禁止现代元素与人物大特写。
