# 枫叶红 · 插画提示词

## 一色一诗 · 图一《寒山石径·枫林晚》 → 01-01.png

竖版9:16中国古典轻水墨国风插画，宋画山水意境转译为深秋气象，时值晚秋黄昏，天气晴冽。远景层叠寒山以淡墨晕染，山脊隐入苍茫暮色；山腰白云缭绕，几处白墙黛瓦人家隐现云雾之间，若隐若现。中景一条石径自画面下方蜿蜒斜上，没入枫林深处，径旁碎石以枯笔皴出。近景与中景之间，大片枫林层林尽染，枫叶红（#C21F30）由深至浅自然过渡，与墨色枝干交织，构成全画视觉重心。枫林边一驾唐代牛车停驻，一位身着青灰圆领袍、戴幞头的文人立于树下，仰首望向满山红叶，身形以工笔细描，面容温润含笑，位于画面下三分之一处偏右，作仰望之姿。前景两三枝红枫垂枝探入画面，叶脉工细，墨枝遒劲。天空留白约百分之三十五，顶部五分之一保持素净宣纸质感，为时钟日期留出空间。画面右上以清雅小楷竖排题「远上寒山石径斜，白云生处有人家」，自右至左，墨色浓淡自然，钤一枚极小朱红篆刻印章。右下角淡金色手写体「azrng」签章，细小如古雅私印，自然融入，不做明显水印。

## 一色一诗 · 图二《霜叶·红于二月花》 → 01-02.png

构图极简的意象特写之作，竖版9:16，宣纸底色温润微黄，绢本质感细腻。画面主体为一枝自左上方斜出伸展的枫枝，占画面约三分之一，枝干以浓淡枯润变化的墨笔写成，遒劲虬曲，末端分出细枝数条。枝上百余片枫叶以工笔细描，五裂叶形分明，叶脉清晰，枫叶红（#C21F30）在叶片上呈现由深红至浅朱的自然浓淡层次，数片叶尖染霜，泛出微微冷白，叶缘留一线暖金光感，似夕阳侧照。枝头凝着两三点欲坠未坠的霜露，晶莹欲滴。画面右下以淡墨勾出两三笔远山剪影，隐约朦胧，其余大面积留白，约占百分之四十五，空灵疏朗，凸显枫叶红的沉静与炽烈。整体低饱和，水墨晕染极轻，工笔与写意相济。画面左侧以行书竖排题「停车坐爱枫林晚，霜叶红于二月花」，自右至左，每列自上而下，墨色有飞白与枯润变化，句侧钤一枚极小朱红篆刻印章。右下角融入极小淡金色手写体「azrng」，形如古雅私印，低调自然，不夺主体。整幅如可装裱的宋人小品。

## 一色一诗 · 图三《坐爱枫林晚》 → 01-03.png

情绪延伸之作，视角由旁观转为身临其境，竖版9:16。观者视线从枫林内部向外望去，前景数株枫树粗壮墨枝自画面两侧斜向框出，红叶层叠垂落，形成天然的枝叶画框，枫叶红（#C21F30）在暮色中深沉如醉。透过枝框，远处山峦起伏，淡墨层层推远，天际被夕照染成枫叶红与暖金交融的晚霞，霞光自画面中上方斜照进来，穿过叶隙，在空气中形成数道柔和光柱。山脚石径尽头隐约一点人家灯火，暖光微小如豆。画面下方近景处，一位身着赭色袍服的唐代旅人背对观者，坐于青石之上，头微仰，凝望远处霞山，姿态松弛旷达，衣纹以简练墨线勾出，身形小巧，位于画面下三分之一居中偏左。地上落叶点点，朱色散落如星，与漫山霞色呼应。留白约百分之三十，顶部保持素净以备时钟显示，水墨轻晕，空灵克制。画面右上以行楷竖排题「霜叶红于二月花」，墨色沉润，旁钤极小朱文印章一枚。右下角淡金色「azrng」手写签章，细小如古雅私印，自然妥帖。

## 一色一源 · 六格册页《霜染枫林晚》 → 02-01.png

最终整图提示词：一张竖版3:4小红书知识插画，中国古典轻水墨与宋画小品风格，宣纸与绢本肌理打底，整体以米白、淡墨、浅灰为基础，传统色"枫叶红"（#C21F30，深沉饱满略带冷意的正红）为全图唯一核心色，仅点缀于枫叶、远山与画面重点处，克制而醒目。画面由六个古风小场景按古籍册页散点式布局自上而下错落排布，场景之间以淡墨枝叶、云气、溪水纹与大面积留白自然衔接，不使用现代漫画边框。第一景：一片枫叶红的五角枫叶自枝头飘落，叶尖留一点未红的淡色，背景是淡墨远山与半角小亭。第二景：霜降清晨，枫枝覆着细白薄霜，叶缘渐渐透红，树下小童呵气搓手仰望。第三景：山道上文人从牛车下来，负手眺望满山红叶，书童挑担踮脚张望，层林以枫叶红点染、近处留白。第四景：书案上摆着盛朱砂、胭脂、茜色的小瓷碟，画师捏一片枫叶逐一比色，神情专注。第五景：岳麓山中一座小亭立于红枫深处，匾额隐约，游人拾级而上，一人回首指树。第六景：远景秋山层林尽染，枫叶红如墨点由浓渐淡，一行雁影掠空，下方大片素净留白。人物小巧生动，工笔细节与写意晕染结合，色彩低饱和，画面古雅通透，仅在场景角落缀以极小的淡金色手写体签章"azrng"，形如一方古雅私印，自然融入宣纸肌理，全图如一本古人留下的趣味颜色博物小册。

第一格《一叶报秋》：米白宣纸上，一片肥硕的五角枫叶以枫叶红（#C21F30）细细晕染，正从枝头飘落，叶尖带一点将红未红的淡色，背景是极淡的远山与半角小亭。配文：别的颜色忙着开春，它攒了一整年，就等秋天一次性红透。

第二格《经霜才红》：霜降清晨，一枝枫树斜出，叶片上覆着细白薄霜，叶缘正一点点透出红意；树下小童缩着脖子呵气搓手，抬头看叶。配文：别的叶子见霜就黄了，枫叶偏偏越冷越红，相当有骨气。

第三格《停车看枫》：山道转弯处，一位戴巾文人刚从牛车上下来，负手远望对面满山红叶；书童挑着书担，也踮脚张望。远山层林以枫叶红点染，近处留白。配文：杜牧看见漫山枫林，直接停车不想走了，还夸它红过二月花。

第四格《红的学问》：文人书案上，三只小白瓷碟分别盛朱砂、胭脂、茜色颜料，画师捏着一片枫叶逐一比对，微微皱眉沉思，枫叶的红明显更深更沉。配文：朱砂太亮，胭脂太艳，枫叶红红得沉稳，像藏了一整个秋天。

第五格《因诗得亭》：岳麓山麓，一座小亭立于层层红枫之间，亭匾隐约可辨，两三游人拾级而上，一人回头指树，似在与同伴争论叶色。配文：长沙爱晚亭，原名红叶亭，后因"停车坐爱枫林晚"改了名。

第六格《秋山落款》：全图收尾处，远景秋山层林尽染，枫叶红如墨点般由浓渐淡，一行雁影掠过天际，下方大片素净留白。配文：枫叶红，是秋天写完落款后，寄给山林的一封信。
