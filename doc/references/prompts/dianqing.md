# 靛青 · 插画提示词

## 一色一诗 · 图一《霜天夜泊》 → 01-01.png

竖版9:16中国古典水墨插画壁纸。深秋后半夜，月已西沉，仅余一弯极淡残月低垂于画面右上角天际，靛青色夜空自上而下由深至浅自然晕染在宣纸底色之上，透出满天寒霜的清冷。一两笔淡墨乌鸦掠过中景天空，翅影细劲。中景：宽阔江面以留白与淡靛青水纹表现，一艘乌篷客船泊于江心偏下，船头一位青衫旅人披衣独坐，面朝江水，神色沉静含愁，身旁一盏小小暖黄灯火。近景：左下数枝经霜江枫斜入画面，红叶转暗，工笔细勾叶脉，写意点染枝干，叶尖凝着薄霜。远景：对岸淡靛青山影空蒙，寒山寺塔影一角隐约可辨，前景清晰、中景柔和、远景淡雅。整体低饱和，水墨为骨、靛青为魂，留白约35%，顶部15%保持简洁。右侧以清雅行楷竖排书写"月落乌啼霜满天，江枫渔火对愁眠"，墨色有自然浓淡与飞白，句末钤一枚极小朱红篆印。右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印。

## 一色一诗 · 图二《一点渔火》 → 01-02.png

竖版9:16极简水墨意象壁纸。夜半江面特写，画面以大片靛青色夜空与江水为主调，天与水的分际隐在雾气里几乎不可辨，绢本质感上带着轻微水墨晕染。视觉中心偏下：一叶渔舟的船头自画面右下斜入，舟上一盏竹编罩着的纸罩渔灯，暖黄微光，是整幅画唯一的暖色；光晕在靛青江面上化开一道细长的倒影，随水纹轻轻摇曳，明灭如呼吸。船头坐着收网的渔人剪影，浓墨简笔勾出，低头小憩，斗笠搁在膝边。上方左角垂入一两枝霜后江枫，叶片半透明，边缘被渔火微微映亮。远处水面上另有一星极淡渔火，若隐若现。构图极简，留白约45%，以靛青的沉静衬一点暖光，克制而空灵。左上留白处以小楷竖排书写"江枫渔火对愁眠"一句，墨灰带自然枯润变化，钤一枚极小朱红印章。右下角融入极小淡金色手写签章"azrng"，低调如私印。

## 一色一诗 · 图三《钟声余韵》 → 01-03.png

竖版9:16水墨情绪延伸壁纸。时间推向夜半钟声敲过之后、黎明将至未至的最深靛青时刻。视角从高处远望姑苏城外江面：整幅画沉入近乎墨色的深靛青中，江面浮起薄薄水雾，以淡墨与留白轻轻扫出，宣纸肌理隐约可见。中景：客船已化作雾中极小的一痕墨点，舱内微光如豆；一尾乌鸦飞远，成为天际两点淡墨。近景：右下以淡墨与浅绛勾出崖岸一角与几竿寒苇，苇絮凝霜，似有钟声的余震仍在苇梢轻颤。远景：寒山寺的檐角剪影与塔尖隐在靛青山影之后，山与天交界处透出一线极淡的鱼肚白，预告天明，靛青由深转浅的渐变极为克制安静。整幅强化"愁绪落定、万籁俱寂"的余韵，低饱和、空灵雅致，留白约40%，顶部保持空阔。左侧以行书竖排书写"夜半钟声到客船"，墨色将尽处带枯笔飞白，钤一枚极小朱红篆印。右下角自然融入极小淡金色手写签章"azrng"，不做明显标识。
