# 藕荷 · 插画提示词

## 一色一诗 · 图一《罗裙一色》 → 01-01.png

竖版9:16中国古典轻水墨国风插画，宋画意境，宣纸绢本质感。盛夏清晨的江南荷塘，宿雨初收，天色薄晴，晨光自右上斜斜照入。中景一位唐代采莲少女立于小小木舟之上，身着与荷叶同色的青绿罗裙，乌发松挽、斜插一支素木簪，半侧身拨开高过人身的莲叶，半张面容隐在花影之后，眉眼含笑、微微低首，朝向画面深处的荷丛，衣袖轻扬。藕荷色（#EDC3AE）不作为铺色，而是自然渲染于初绽的荷花花瓣、少女颊边微光与晨雾暖意之中。前景两三柄放大的荷叶与一朵饱满菡萏，叶脉以工笔细勾、边缘写意晕染并微微虚化；中景人与舟、莲丛层次分明；远景荷塘渐淡，水天交界处以淡墨与藕荷色轻扫，雾气朦胧。水面以留白与细笔水纹表现倒影。低饱和、空灵雅致，留白约三分之一，顶部五分之一保持素净。画面右侧竖排行楷书写"荷叶罗裙一色裁，芙蓉向脸两边开"，自右至左，墨色有浓淡飞白，诗末钤一枚极小朱红篆刻印章。右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印，低调不夺画面。

## 一色一诗 · 图二《菡萏含露》 → 01-02.png

## 一色一诗 · 图三《闻歌始觉》 → 01-03.png

竖版9:16中国古典水墨国风插画，与前三幅视角、时间、情绪均不同：薄暮时分，无人之境，以景代情，画出"闻歌始觉有人来"的余韵。采用略高的俯视视角，一叶空空的小木舟横在荷塘深处，舟上搁一顶斗笠与半篮新采的莲蓬，采莲人已没入密密层层的莲叶之间不见踪影，只余舟边一圈圈缓缓荡开的水纹，仿佛歌声仍在水面行走。暮色将天空与水面染成温柔的藕荷色（#EDC3AE），霞光在远处水天交界处轻轻燃起一线暖意，与灰墨荷叶的青影层层交叠，色彩融入天光水色而非平涂。前景是两三柄压低的荷叶剪影，以淡墨写就；中景空舟与涟漪是视觉重心；远景荷塘渐入苍茫暮霭，由实入虚。水墨晕染略重，暮气氤氲而主体清晰，低饱和、清寂中带灵动，留白约三成，顶部保持素净以留出时间日期位置。画面左侧竖排行书书写"乱入池中看不见，闻歌始觉有人来"，自右至左，墨色沉静有浓淡枯润，诗末钤一枚极小朱红篆印。右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印，不夺画面。

## 一色一源 · 六格册页《藕荷·问色荷塘》 → 02-01.png

第一格《荷塘取色》：夏末荷塘一角，淡墨远山，一叶小舟，戴笠采藕人持篙而立。荷花初开与将谢并存，花瓣尖端与花心晕着藕荷色，水面以极淡墨线勾出水纹。配文：今天要说的颜色，老家就在这片夏末的荷塘里。

第二格《藕＋荷》：塘边青石上，竹篮里躺着切开的生藕，断面莹白泛粉；石缝边一朵将谢的荷花，褪成柔和的灰粉。两个颜色遥遥呼应，小童一手点着藕、一手点着花，似有所悟。配文：一半是藕的白粉，一半是荷的柔粉，名字就这么凑齐了。

第三格《灶上见色》：小院灶间，陶罐炖藕热气袅袅，妇人揭开罐盖，熟藕断面泛出粉中带灰紫的藕荷色；灶边小凳上，小童捧着空碗仰头等候，鼻尖快要凑到罐边。配文：常见解释认为：藕荷更像煮熟的藕，粉里带一点灰紫。

第四格《染师比色》：染坊前，老师傅双手举起新染好的布，向着荷塘方向迎光比对，布色与塘中荷花几乎难分；学徒抱着一册色样立于一旁，探头偷学。晾架上几匹布随风轻摆。配文：染色的老师傅，最懂怎么向荷塘借色。

第五格《不是淡紫》：文人书案，三枚小色笺一字排开，分别题着"藕色""藕荷""淡紫"——藕色最浅偏白，淡紫偏冷偏艳，藕荷居中，灰一分、稳一分；文人执笔悬于色笺上方，眯眼比对。配文：藕色更浅，淡紫更艳，藕荷胜在那一分灰。

第六格《藕断丝连》：月下荷塘，青衣人立于岸边掰断一截藕，银亮细丝在月光里牵连不断，袖口露出一抹藕荷色；半塘荷叶作淡墨剪影，一两片藕荷色花瓣浮在水面，大面积留白。配文：颜色会淡，丝还连着——藕荷的温柔，也是这样。
