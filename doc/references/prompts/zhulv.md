# 竹绿 · 插画提示词

## 一色一诗 · 图一《幽篁抚琴》 → 01-01.png

竖版9:16中国古典水墨国风插画，宋画意境。晴夜无风，深山幽篁竹林中，一位唐代文人独坐抚琴。画面下方三分之一处是一块平缓青石，石上文人盘膝而坐，身着竹绿色宽袖襕衫，衣袍以淡墨勾勒、以竹绿#1BA784分染，神态安闲垂目，双手抚于七弦琴上，身体朝向右侧竹林深处，位置偏左下，与右上月亮遥相呼应。前景左下几竿修竹斜出，叶片工笔细勾，竹绿浓淡相间，近实远虚；中景竹林层层退远，竹竿以淡墨写出，挺拔疏朗；远景大片留白化作夜雾，一轮淡金圆月悬于右上，月色如水，在石面与琴面留下微光。宣纸质感，水墨轻晕，低饱和，空灵雅致，留白约百分之四十，顶部百分之十八保持简洁素净。画面右上竖排行书题写"独坐幽篁里，弹琴复长啸"，从右至左，墨色深墨带自然飞白，句下一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写签章"azrng"，形如古雅私印，低调无痕。

## 一色一诗 · 图二《明月相照》 → 01-02.png

竖版9:16中国古典水墨国风插画，宋画意境，极简构图，不出现人物。只取诗中"明月来相照"一意：一丛竹，一轮月。画面上三分之一处悬一轮满月，以淡金微黄染出，边缘微微洇开，如宣纸上化开的月光。月亮右下侧，三五竿修竹自画面底部斜伸而上，只取中段枝叶入画，叶片以竹绿#1BA784细笔勾出，深浅相间：向月的一面被照得透亮，竹绿清润；背月一面沉入淡墨，形成含蓄的明暗层次。两三片竹叶轻掩月轮边缘，月与竹彼此映衬，是全画唯一的呼应。画面中下部大片留白，仅以极淡水墨横扫一两笔，似雾似水，空灵干净。绢本宣纸质感，笔触松弛，水墨轻晕，低饱和克制，留白约百分之四十五，顶部百分之十八保持素净，为手机时间日期留出空间。画面右侧竖排小楷题写"深林人不知，明月来相照"，从右至左，墨色温润，末字旁一枚极小朱红篆印。右下角自然融入极小淡金色手写签章"azrng"，如古雅私印。

## 一色一诗 · 图三《竹间望月》 → 01-03.png

竖版9:16中国古典水墨国风插画，宋画意境，采用自下而上的仰视视角，是前两幅之外的情绪延伸。不再旁观抚琴人，而是化身为竹林中仰望的那双眼：视角从竹林深处向上，透过层层竹梢望向高处的夜空。画面中央偏上，一轮淡金满月悬于墨蓝夜空，四周竹叶以竹绿#1BA784染就，环绕月轮呈放射状层层铺开；近处叶片工笔细致、竹绿稍浓，向外渐渐淡虚，最终没入大片淡墨夜雾与留白之中，空间层次由近及远一望即知。月光自上而下透过叶隙洒落，几缕极淡的光痕斜穿画面，叶隙间隐约可见细碎月斑。画面最下缘，以淡墨虚写一角竹绿衣袖与一截琴尾，暗示抚琴人正枕石仰望，人物几不可辨，孤独却辽阔。宣纸质感，水墨轻晕，低饱和空灵，留白约百分之三十五，顶部百分之十八保持素净。左上竖排行楷题写"弹琴复长啸"，从右至左，墨色由润渐枯带飞白，句旁一枚极小朱红篆刻印章。右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印。

## 一色一源 · 六格册页《一竿竹绿，半窗清影》 → 02-01.png

最终整图提示词：竖版4:5小红书知识插画，中国古典轻水墨风格，兼具宋画小品与古籍博物图鉴质感。米白色宣纸肌理为底，画面由六个散点小场景自上而下组成，仿佛一册古雅颜色小志徐徐展开，场景之间以淡墨竹枝、飞云气纹与浅浅水痕自然衔接，四周留白充足，呼吸感强。传统色"竹绿"（清新带青的竹绿色，参考色值#1BA784）是全图唯一点睛之色，克制地出现在新竹枝叶、竹帘、笔筒与窗上竹影之间，其余以淡墨、浅灰、米白晕染为主，整体低饱和、色彩克制。场景一：春雨初歇的竹园，新竹破土而出，竹绿枝叶挂露，雾气微起，小童踮脚仰头张望。场景二：一竿修竹特写，竹节分明，文人伸手轻抚竹竿，侧头端详那层青色竹皮。场景三：文人书房，竹帘半卷，光斑落案，竹制笔筒插笔，榻边倚竹夫人，茶烟袅袅。场景四：画师立于窗前凝视庭竹，提笔悬腕欲落未落，窗外绿竹与纸上墨竹隔窗相对。场景五：小院借居，主人指着新种竹苗含笑，小童抱竹而立歪头喘气。场景六：月夜，疏疏竹影落在窗纸上，一盏茶一卷书，人倚榻安睡，竹绿渐淡收尾。人物皆小巧生动，衣纹工笔细致，神情含蓄带趣，动作有故事感，工笔与写意结合。各场景角落配极少量竖排古风小字标题，字体清雅。右下角自然融入淡金色手写体签章"azrng"，形如古雅私印，低调融于纸面，不似水印，无粗黑边框、无现代元素。

第一格《竹绿登场》：春雨初歇的竹园，一竿新竹破土拔节，竹绿枝叶上挂着露珠，雾气微起。一个小童踮着脚、仰着头张望新竹，衣角被风轻轻带起。配文：春雨一过，新竹冒头，这种自带清凉感的绿，今天讲它。

第二格《名字很直》：一竿修竹的近景特写，竹节分明，表面那层青色竹皮格外清晰。一位文人伸手轻抚竹竿，侧头端详，似乎在心里给这颜色对号入座。配文：古人取名很诚实：竹子的绿就叫竹绿，竹皮那层青还叫竹青。

第三格《案头常客》：文人书房一角，竹帘半卷，光斑落在案头。竹制笔筒插着毛笔，榻边倚着竹夫人，茶烟袅袅。竹绿色在帘条与器物间低调呼应。配文：竹帘、竹席、竹笔筒……古人一天见它，可能比见家人还勤。

第四格《胸有成竹》：画师立于窗前，凝视庭中绿竹良久，纸上墨竹将成未成，他提笔悬腕、欲落未落。窗外实景竹与纸上墨竹隔窗相对。配文：画竹高手下笔前，心里已长好一片竹林，胸有成竹。

第五格《何日无竹》：小院借居场景：主人指着刚种下的几竿新竹含笑自语，小童抱着最后一根竹苗站在土坑边，累得歪着头。典出《世说新语》王子猷借宅种竹。配文：借住空宅也要先种竹：何可一日无此君！

第六格《一色清欢》：月夜收尾。竹影疏疏落在窗纸上，案头一盏茶、一卷书，人已倚榻安睡，竹绿色在月色中渐渐转淡，全图归于静谧。配文：夜深了，竹影落上窗纸，绿色淡了，诗意却更浓。
