# 海棠红 · 插画提示词

## 一色一诗 · 图一《故烧高烛照红妆》 → 01-01.png

竖版9:16中国古典轻水墨国风插画，宋画意境，春夜场景。月色转过长廊，香雾空蒙，画面主体为一株盛放的海棠树，花色取中国传统色海棠红，深浅点染，繁密而姿态清雅，在夜色中透出温润的红。树下立一位宋代文人，身着素色交领长袍，外披薄衫，手持一支高烛，微微俯身向花，神态温和专注，似怕惊扰花眠；人物置于画面下方三分之一处，侧身朝向海棠。前景为斜出的几枝海棠与烛台，工笔细致；中景为人物与花树，轮廓柔和；远景以淡墨渲染庭院回廊与一轮转过的圆月，廊柱隐入夜雾。烛光暖黄与月色清辉在花瓣上交融，海棠红是画面唯一的浓色，其余以淡墨、米白与青灰经营。宣纸质感，轻微水墨晕染，留白约百分之三十五，顶部五分之一为简洁夜空。画面右侧竖排行书题写「东风袅袅泛崇光，香雾空蒙月转廊。只恐夜深花睡去，故烧高烛照红妆」，墨色有浓淡枯润变化，钤一枚极小朱红篆印。右下角自然融入极小的淡金色手写签章「azrng」，形如古雅私印，低调不抢眼。

## 一色一诗 · 图二《只恐夜深花睡去》 → 01-02.png

竖版9:16中国古典轻水墨国风插画，宋画意境，构图极简空灵，意象特写。深夜近半，画面仅两物：一枝自左上方垂落的海棠，与右下方一支正在燃烧的红烛。海棠花以传统色海棠红点染，初绽与盛放相间，花瓣工笔细腻，脉络隐现，边缘略带胭脂色渐变；红烛烛身素白，烛焰暖黄，微微摇曳，将光晕轻柔投向花枝，花影淡淡投在素色底上，仿佛为花照亮红妆。背景大面积留白，仅以极淡墨色晕出夜的静气，上部近乎素白，留白约百分之四十五，顶部五分之一完全简洁以容纳手机时间。前景为最靠近视线的两三朵海棠，纤毫毕现；中景花枝渐柔；远景全部虚淡入夜色。整体低饱和，海棠红与烛焰暖黄是仅有暖色，克制雅致，绢本质感，水墨轻染。画面左上竖排小楷题「只恐夜深花睡去，故烧高烛照红妆」，墨色带自然飞白与枯润，钤一枚极小朱红篆印。右下角自然融入极小的淡金色手写签章「azrng」，如古雅私印，不构成明显标识。

## 一色一诗 · 图三《晓雾余红》 → 01-03.png

竖版9:16中国古典轻水墨国风插画，宋画意境，情绪延伸之作，视角转为清晨，画意安静而略带怅惘。夜色已尽，晨雾未散，一弯残月淡淡挂在天际。视线俯向庭院一角：青石阶前，昨夜的高烛已燃尽，只余短短烛台与一缕将熄的白烟；数瓣海棠红的花瓣散落在石阶与苔痕之间，颜色依旧温润，像红妆未卸。阶边一株海棠树只露出下半段枝干，上部隐入晓雾，隐约可见残花疏落。远处回廊一角以淡墨勾出，廊下空寂无人，惜花的人已经离去，唯有落花记得那一夜的烛光。光线为清晨冷白与残月微光交织，石阶上的海棠红花瓣是全画最温暖的一点。前景为落瓣与残烛，工笔细致；中景石阶与树干柔和；远景廊影与雾色淡雅，空间层次分明。宣纸质感，水墨晕染轻柔，留白约百分之四十，顶部保持简洁晨空以预留手机时间区域。画面右上竖排行楷题「只恐夜深花睡去」，下钤一枚极小朱红篆印。右下角自然融入极小的淡金色手写签章「azrng」，形如古雅私印，低调融入画面。
