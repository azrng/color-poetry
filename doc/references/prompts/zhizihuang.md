# 栀子黄 · 插画提示词

## 一色一诗 · 图一《雨过山村》 → 01-01.png

竖版9:16中国古典轻水墨国风插画，宋画意境，宣纸绢本质感。初夏雨霁清晨的江南山村：远景淡墨青山隐入薄雾，山脚两三户青瓦白墙人家，屋瓦被雨水浸得微润；中景竹林苍翠欲滴，竹溪自山间蜿蜒而下，一座微微倾斜的木板桥横跨溪上；前景为一方小院，院中栀子树枝叶舒展，数朵白花缀着雨珠，其中一两朵将谢之花晕染出栀子黄（#EBB10D）的暖调，檐下竹匾里晾着几枚黄栀子果，与天光彼此呼应。两名村妇着靛蓝粗布衣、挽袖提篮，一前一后走向板桥，背影小小，神态从容，是去浴蚕的农忙光景。雨后初晴的柔光洒落水面与花叶，栀子黄的暖意轻轻晕开在湿瓦、溪流与花苞之间。工笔细节与写意留白结合，轻微水墨晕染，前景清晰、中景柔和、远景淡雅，低饱和空灵雅致，留白约三分之一，顶部天空简洁为手机时间日期预留。画面右侧竖排小楷书法《雨过山村》全诗，从右至左逐列书写，墨色有自然浓淡与飞白枯润，诗末钤一枚极小朱红篆刻印章，右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印。

## 一色一诗 · 图二《庭中栀子》 → 01-02.png

竖版9:16中国古典轻水墨国风插画，意象特写构图，宋人花卉小品意境，宣纸绢本质感。雨后中庭，一枝栀子花自画面右上方斜入，是全画唯一主体：深墨绿叶舒展垂坠，叶尖悬着将落未落的雨珠，三四朵栀子洁白盛放，花瓣以细笔勾出湿润通透的质感，花心微微泛黄；其中一朵将谢之花完整呈现栀子黄（#EBB10D）的暖金色，花瓣边缘晕出由白入黄的自然渐变，是全画视觉焦点；另有青黄花苞低垂未开。背景大面积留白，仅以淡墨轻轻晕染雨雾的湿气，暗示粉墙一角与半卷竹帘，简洁空灵。天光自左上方斜落，在花瓣与雨珠上点出微暖光晕，栀子黄的暖光在白花之间静静流动。工笔勾花点蕊，写意留白衬底，水墨晕染极轻，主体集中于画面中下部，留白约四成，顶部至简为手机时间预留。画面左侧竖排清雅行楷书法"妇姑相唤浴蚕去，闲看中庭栀子花"，从右至左排列，深灰墨色带自然枯润飞白，句末钤一枚极小朱红篆印，右下角自然融入极小淡金色手写签章"azrng"，低调如私印一枚。

## 一色一诗 · 图三《山村灯暖》 → 01-03.png

竖版9:16中国古典轻水墨国风插画，情绪延伸之作，宣纸质感。时间移至雨后深夜，视角转为山居近景：一扇木格纸窗占据画面中下方，窗内一盏油灯透出栀子黄（#EBB10D）的暖光，窗纸被染成柔软的微黄，灯影里隐约映出屋内陶罐与数枚黄栀子果的剪影，暗示染料的来处；窗外一枝栀子斜倚窗棂，白花与墨叶雨痕未干，在暖光边缘镶出一圈浅浅金边。夜色以淡墨层层晕开，远景只余深浅山影与两三点极小的灯火，呼应"雨里鸡鸣一两家"的人间烟火。构图如自窗内向外凝望，光由内向外漫射，安静温暖，带着夜里独醒的清寂与妥帖。工笔刻画窗棂灯影，写意晕染夜山，低饱和克制，前景清晰、远景淡雅，留白约三分之一，顶部夜空至简为手机时间日期预留。画面右侧竖排小楷书法"雨里鸡鸣一两家，竹溪村路板桥斜"，从右至左，墨色浓淡自然带飞白，句末钤一枚极小朱红印章，右下角自然融入极小淡金色手写签章"azrng"，古雅低调。

## 一色一源 · 六格册页《栀子染夏》 → 02-01.png

最终整图提示词：一张竖版4:5的小红书知识插画，仿宋人小品与古籍博物册页气质。整体以做旧宣纸为底，米白微黄，留白充分，六个小场景以栀子枝叶、晾布染线与淡墨云气自然串联，不用现代边框分隔。主题传统色为栀子黄（#EBB10D，明亮温暖的蛋黄金），克制地出现在栀子果实、染缸液面、晾晒黄绢、筐中果子、瓷碟果汁、茶汤与案上丝绢等关键处，是全图的视觉记忆点；其余色调为淡墨、浅灰、米白，辅以少量浅青与赭石，整体低饱和。场景一：初夏庭院，栀子白花盛开，淡墨线勾花香，青衣女子俯身嗅花，狸猫蹲于石阶。场景二：秋枝结出橙红栀子果，老画师捏果对光细看、指尖染黄，瓷碟中果汁洇出金黄，旁置古酒器"卮"对照。场景三：染坊内匠人把白绢浸入大缸金黄染液，竹竿上黄绢轻摆，小童踮脚够布。场景四：山坡栀子田，农人采果装筐，棚下账房先生拨算盘，角落小楷题"千亩栀茜，其人与千户侯等"。场景五：文人案头，藏红花与栀子果并列瓷碟，两人执物比色低语，茶汤金黄。场景六：暮色书房，青瓷瓶插栀子枝果，案上摊开栀子黄丝绢，茶烟袅袅，远山淡墨。画风为中国古典轻水墨与工笔小插画结合，绢本肌理，工笔细节与写意留白相济，人物小巧生动、动作含趣，无现代元素。画面点缀少量古风小字与色名题签"栀子黄"。右下角融入一枚极小的淡金色手写体签章"azrng"，形如古雅私印，与纸面自然融合、不抢眼，整体如一册古人留下的颜色博物小志。

第一格《栀子登场》：初夏庭院一角，一丛栀子白花初绽，花香化作淡墨细线飘向檐角；浅青襦裙的女子俯身嗅花，一只狸猫蹲在石阶上抬头张望。花蕊处一点栀子黄，与题签色名相呼应。配文：初夏满院香的栀子，开的是白花，凭什么名字带"黄"？

第二格《色藏果中》：秋日枝头白花谢尽，结出饱满的橙红果实；老画师捏果对着日头细看，指尖已被染黄；白瓷碟里碾开的果子洇出金黄汁液，旁置一只古酒器"卮"作形状对照。配文：白花只是预告，金黄全攒进秋果——果形似酒器"卮"，名字也由此来。

第三格《一缸直染》：染坊内，短褐匠人将白绢缓缓浸入大缸，缸中栀子染液金黄透亮；竹竿上晾着几匹刚染好的黄绢随风轻摆，小童踮脚偷摸垂下来的布角。配文：别的染料要媒染助攻，栀子泡水就能上色，省事到匠人偷笑。

第四格《千亩栀茜》：山坡梯田间大片栀子田，农人提篮采果、满筐金黄；凉棚下账房先生拨着算盘嘴角上扬。画面一角以小楷题"千亩栀茜，其人与千户侯等"。配文：《史记》说种千亩栀子，收入可比千户侯——汉代的硬核经济作物。

第五格《同款名贵》：文人案头，白瓷小碟里盛几粒红色藏红花，旁边一碟金黄栀子果；两位文人各执一物凑近比色、低声讨论，茶盏中的茶汤也是同款金黄。配文：栀子黄的主色素叫"藏红花素"，和名贵藏红花竟是同款成分。

第六格《一色栀香》：暮色书房，窗边青瓷瓶插一枝带果栀子；案上摊开一段栀子黄丝绢，茶烟袅袅绕过绢面，远山一痕淡墨。右下角落一枚极小的淡金"azrng"私印。配文：白花谢了，颜色留下——栀子把整个夏天，染进了一方绢上。

## 一色一物 · 图一《汉绢清供》 → 03-01.png

中国古典轻水墨与精致国风插画结合的东方静物画，竖版4:5构图，米白色宣纸质感背景，带细微纸纹与轻微墨色晕染。画面中下部，深色木案上平放一匹折叠整齐的汉代黄色绢帛，织物呈栀子黄——温暖的金黄色，微透橙意，边缘有自然折痕与柔和丝光，织纹隐约可见。案角置一小碟干栀子果，橙红色小果与素色粗陶碟形成微妙的色彩呼应；旁侧一段素白麻绳与半卷竹简，皆低饱和、不抢主体。案外大面积留白，顶部尤为空阔，仅以一缕极淡墨影收住画面。光线自左上柔和斜入，绢面明暗过渡自然。整体色彩克制：米白、宣纸色、浅灰、淡墨、墨黑为基底，栀子黄为唯一鲜亮核心。画面右上以竖排小楷写"栀子黄"，其下小一号写"汉代染绢"，淡墨色，古籍式排版。右下角融入极小的淡金色手写体签章"azrng"，形如古雅私印，低调自然，不做Logo；旁可加一枚极小朱红篆刻小印。禁止现代摄影棚感、玻璃展柜、现代字体与卡通元素。

## 一色一物 · 图二《一寸金黄》 → 03-02.png

竖版4:5，中国古典绘画质感与博物馆级细节审美，米白宣纸底色微微晕开的局部特写构图。画面主体为一匹汉代黄绢的极近局部：经纬丝线交织的罗纹肌理清晰可辨，丝缕之间呈现植物染特有的不均匀色泽——迎光处是明亮的栀子金黄，像刚剖开的新鲜果肉；背光与折痕处沉淀为柔和的赭金与暖土黄；个别丝线边缘泛出极淡的橙红，正是栀子果实的底色。丝的光泽沿织纹缓缓流动，形成细密的明暗涟漪；一两处细微的经线起伏，让画面有了呼吸。边缘自然虚化，融入宣纸底色，保留大量呼吸感。色彩关系以栀子黄为绝对核心，辅以米白、浅灰、淡墨；同一种黄呈现深浅、浓淡、冷暖与光泽的丰富层次，绝不呈现为现代纯色色块。画面左下以竖排小楷写一行："果入染缸，丝上生暖。"清雅行书，淡墨色，古籍式小字排版。右下角极小淡金色手写签章"azrng"，形如古雅私印，旁可加一枚极小朱红篆印。禁止高清产品照、纯色色块、现代无衬线字体。

## 一色一物 · 图三《染园晾绢》 → 03-03.png

竖版4:5，中国古典水墨与宋画小品叙事感，还原西汉染坊的午后庭院场景。画面中部偏下，庭院里立着几组木质晾架，数匹刚染好的栀子黄绢帛垂挂于竹竿之上，随风轻扬，黄绢在斜阳中透亮如新果，是全画最亮的色彩。庭院一角置一口大陶染缸，缸沿染渍斑驳，旁边竹匾里摊晒着橙红色的干栀子果；一位穿素色汉式短褐的染工立于晾架之间，正抬手查看绢色，人物比例小、只作环境辅助角色，不做面部特写。远处一段夯土院墙与檐角，一株栀子树斜出，绿叶间缀几朵白花，以淡墨写就。光线为午后暖光，长影斜铺，空气中带薄薄的尘埃感。整体色彩克制：米白、宣纸色、淡灰、墨色为基，栀子黄为魂，远处淡墨收势。画面右下竖排小楷："一果一色，染尽汉家衣。"淡墨行楷。右下角极小淡金色手写签章"azrng"，形如古雅私印，旁可加一枚极小朱红篆印。禁止现代建筑、现代人物、卡通、二次元与高饱和国潮风。
