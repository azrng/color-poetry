# 栀子黄 · 插画提示词

## 一色一诗 · 图一《雨过山村》 → 01-01.png

竖版9:16中国古典轻水墨国风插画，宋画意境，宣纸绢本质感。初夏雨霁清晨的江南山村：远景淡墨青山隐入薄雾，山脚两三户青瓦白墙人家，屋瓦被雨水浸得微润；中景竹林苍翠欲滴，竹溪自山间蜿蜒而下，一座微微倾斜的木板桥横跨溪上；前景为一方小院，院中栀子树枝叶舒展，数朵白花缀着雨珠，其中一两朵将谢之花晕染出栀子黄（#EBB10D）的暖调，檐下竹匾里晾着几枚黄栀子果，与天光彼此呼应。两名村妇着靛蓝粗布衣、挽袖提篮，一前一后走向板桥，背影小小，神态从容，是去浴蚕的农忙光景。雨后初晴的柔光洒落水面与花叶，栀子黄的暖意轻轻晕开在湿瓦、溪流与花苞之间。工笔细节与写意留白结合，轻微水墨晕染，前景清晰、中景柔和、远景淡雅，低饱和空灵雅致，留白约三分之一，顶部天空简洁为手机时间日期预留。画面右侧竖排小楷书法《雨过山村》全诗，从右至左逐列书写，墨色有自然浓淡与飞白枯润，诗末钤一枚极小朱红篆刻印章，右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印。

## 一色一诗 · 图二《庭中栀子》 → 01-02.png

竖版9:16中国古典轻水墨国风插画，意象特写构图，宋人花卉小品意境，宣纸绢本质感。雨后中庭，一枝栀子花自画面右上方斜入，是全画唯一主体：深墨绿叶舒展垂坠，叶尖悬着将落未落的雨珠，三四朵栀子洁白盛放，花瓣以细笔勾出湿润通透的质感，花心微微泛黄；其中一朵将谢之花完整呈现栀子黄（#EBB10D）的暖金色，花瓣边缘晕出由白入黄的自然渐变，是全画视觉焦点；另有青黄花苞低垂未开。背景大面积留白，仅以淡墨轻轻晕染雨雾的湿气，暗示粉墙一角与半卷竹帘，简洁空灵。天光自左上方斜落，在花瓣与雨珠上点出微暖光晕，栀子黄的暖光在白花之间静静流动。工笔勾花点蕊，写意留白衬底，水墨晕染极轻，主体集中于画面中下部，留白约四成，顶部至简为手机时间预留。画面左侧竖排清雅行楷书法"妇姑相唤浴蚕去，闲看中庭栀子花"，从右至左排列，深灰墨色带自然枯润飞白，句末钤一枚极小朱红篆印，右下角自然融入极小淡金色手写签章"azrng"，低调如私印一枚。

## 一色一诗 · 图三《山村灯暖》 → 01-03.png

竖版9:16中国古典轻水墨国风插画，情绪延伸之作，宣纸质感。时间移至雨后深夜，视角转为山居近景：一扇木格纸窗占据画面中下方，窗内一盏油灯透出栀子黄（#EBB10D）的暖光，窗纸被染成柔软的微黄，灯影里隐约映出屋内陶罐与数枚黄栀子果的剪影，暗示染料的来处；窗外一枝栀子斜倚窗棂，白花与墨叶雨痕未干，在暖光边缘镶出一圈浅浅金边。夜色以淡墨层层晕开，远景只余深浅山影与两三点极小的灯火，呼应"雨里鸡鸣一两家"的人间烟火。构图如自窗内向外凝望，光由内向外漫射，安静温暖，带着夜里独醒的清寂与妥帖。工笔刻画窗棂灯影，写意晕染夜山，低饱和克制，前景清晰、远景淡雅，留白约三分之一，顶部夜空至简为手机时间日期预留。画面右侧竖排小楷书法"雨里鸡鸣一两家，竹溪村路板桥斜"，从右至左，墨色浓淡自然带飞白，句末钤一枚极小朱红印章，右下角自然融入极小淡金色手写签章"azrng"，古雅低调。
