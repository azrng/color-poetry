# 茉莉黄 · 插画提示词

## 一色一诗 · 图一《夏庭熏香》 → 01-01.png

竖版9:16中国古典轻水墨国风插画，宋画意境。南宋夏夜庭院一角：前景为一丛盛放的茉莉，细白花朵缀于青灰枝叶间，工笔勾花、写意点叶，花瓣边缘被暖光染上极淡的茉莉黄；中景为半开的支摘窗与白墙黛瓦，窗内一盏矮烛透出温润的茉莉黄光晕，柔和漫过窗纸，映亮案头青瓷瓶中斜插的一枝茉莉，这缕烛光是画面唯一的暖光源；远景为朦胧月色下的院墙与一角芭蕉，淡墨轻扫，层层退远。天空留白近三分之一，近月处晕染一丝茉莉黄的月华，画面顶部保持素净，为手机时间日期留出空间。整体低饱和、清雅空灵，宣纸绢本质感，水墨晕染自然，前景清晰、中景柔和、远景淡雅。画面右侧以清雅小楷竖排书写"一卉能熏一室香，炎天犹觉玉肌凉"，墨色深墨微带飞白枯润，诗末钤一枚极小朱红篆刻印章。右下角暗处自然融入极小淡金色手写签章"azrng"，形如古雅私印，低调不夺目。

## 一色一诗 · 图二《一枝琼雪》 → 01-02.png

竖版9:16中国古典轻水墨国风插画，宋画意境，极简构图，与图一场景完全不同。画面主体仅一枝茉莉：自右上角以柔韧弧线斜出，横贯画面上部三分之一，枝条以淡墨写出，疏朗有致；枝上五七朵茉莉，或盛放或含苞，工笔细勾花瓣，花心微微晕染茉莉黄的暖调；叶片青灰，写意点染，浓淡相宜。背景大面积留白，约占画面四成以上，绢本肌理细腻；留白并非全空——画面左侧自上而下以茉莉黄淡淡晕开一层柔光，如月色，如烛晕，边缘自然虚化，令白色花瓣在暖黄光里显得温润生香。无人物，无建筑，无器物，仅以一枝花与一片光表现"一卉能熏一室香"的通感。画面左下方以清雅行楷竖排书写"一卉能熏一室香"，墨色深墨，有自然枯润与飞白变化，句末钤一枚极小朱红篆印。整体低饱和、静气克制，顶部留白素净。右下角自然融入极小淡金色手写签章"azrng"，如古雅私印，隐于画面。

## 一色一诗 · 图三《枕畔凉宵》 → 01-03.png

竖版9:16中国古典轻水墨国风插画，宋画意境，室内小景，视角与前两幅截然不同。画面取闺阁卧榻一角：下方为一张凉簟竹榻，纹理以细墨线轻轻勾出；薄纱帐自画面上方垂落半幅，以极淡墨与留白表现，朦胧透光；枕畔横放一枝刚折下的茉莉，花瓣半开，是全画焦点。花枝旁一盏小小油灯已熄，灯盏却仿佛尚存余温，透出一点茉莉黄的微光，与窗外渗入的清冷月色在席面上交叠——一暖一凉，正是"炎天犹觉玉肌凉"的触感。远处窗格以淡墨虚写，窗外夜色几不可见，画外更觉幽深。整体留白约四成，低饱和、静谧幽独，以景代情，不出现人物。宣纸质感，水墨晕染轻微，前景花枝清晰，中景纱帐柔和，远景窗影淡雅。画面右侧竖排小楷书写"自折琼枝置枕旁"，墨色深墨，浓淡与飞白自然，句末钤一枚极小朱红印章。右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印，低调融入画面。

## 一色一源 · 六格册页《茉莉黄·夜香入盏》 → 02-01.png

最终整图提示词：竖版 4:5 中国传统色知识插画，宣纸册页式散点布局，中国古典轻水墨结合宋画小品与古籍博物图鉴风格，米白宣纸肌理打底，整体低饱和、色彩克制，大量留白。核心传统色为"茉莉黄"（#F8DF72，温柔明亮的浅暖黄），在画面中多点呼应而不大面积铺满。全图六个小场景，由一枝蜿蜒的茉莉枝条、袅袅茶烟与淡墨水纹自然串联：上部第一景，夏日窗下小案上，青瓷盖碗中茉莉花茶茶汤呈温柔的茉莉黄，热气袅袅，几朵干茉莉散落案头；第二景特写一枝白茉莉，花瓣舒展，花心藏一簇嫩黄花蕊，旁边几朵干透的茉莉蜷缩泛黄，古装画师执笔俯身对花调色；中段第三景夏夜庭院，宋代女子对铜镜簪茉莉，鬓边缀小白花，小童捧花篮在旁偷笑；第四景茶坊夜色，匠人围坐竹匾，将茉莉花与茶叶层层铺拌窨制，一人俯身闻香；第五景文人案头展开小色谱，鹅黄、缃色、杏黄、茉莉黄四枚色签一字排开，两位老叟执签比对琢磨；底部第六景暮色远山下，一株茉莉临窗而立，花影落入盏中，茶汤正黄，旁题淡墨小楷"人间第一香"。人物小巧生动、动作含趣，工笔细节与写意笔法结合，水墨负责古意，茉莉黄负责记忆点，小人物负责趣味。右下角留白处钤一枚极小的淡金色手写体签章"azrng"，形如古雅私印，低调融入纸面，不做明显水印。

第一格《盏中黄》：夏日窗下小案，一只青瓷盖碗中盛着茉莉花茶，茶汤呈温柔的茉莉黄，热气袅袅升起；案头散落几朵干茉莉，窗外透进柔和天光。配文：先上一盏茶。这抹温柔的黄，跟白茉莉到底什么关系？

第二格《白花心事》：特写一枝茉莉：白瓣舒展，花心藏着一簇嫩黄花蕊；旁边几朵干透的茉莉已蜷缩泛黄，像小纸团。一位古装画师执笔俯身，盯着花心认真调色。配文：茉莉是白的，但花心微黄，晒干后更是黄得理直气壮。

第三格《鬓边凉》：夏夜庭院，烛光与月色相映。宋代女子对镜将一朵茉莉簪上鬓边，身旁小童捧着花篮捂嘴偷笑，石桌上还搁着几串待簪的小白花。配文：宋代姑娘的夏日标配：鬓边簪茉莉，香气自带降温效果。

第四格《夜窨花》：茶坊夜景，灯火昏黄。匠人们围坐竹匾前，将茉莉鲜花与茶叶层层铺拌窨制，一人俯身贴近花堆闻香，神情陶醉，旁边茶筐堆叠。配文：茉莉夜里吐香最盛，窨茶师傅只好跟着花儿上夜班。

第五格《黄分几等》：文人书案上摊开一卷小色谱，鹅黄、缃色、杏黄、茉莉黄四枚色签一字排开，两位老叟各执一签、蹙眉比对，谁也不服谁。配文：黄和黄大不同：鹅黄偏青，杏黄偏橙，茉莉黄像下午四点的太阳。

第六格《第一香》：暮色远山，一株茉莉临窗而立，花影落进盏中，茶汤正黄。画面一侧题一行淡墨小楷"人间第一香"，收束全卷。配文：宋人诗里夸它是"人间第一香"，这抹黄，也香了千年。

## 一色一物 · 图一《黄釉瓷碗·案头清供》 → 03-01.png

竖版4:5构图，中国古典轻水墨与精致国风插画结合的博物馆静物美学。画面中下部居中放置一只明代黄釉瓷碗：撇口、弧腹、圈足，造型端正简练，通体施柔暖的黄色釉，色调接近茉莉黄的浅暖黄，釉面温润如凝脂，隐约有蜡质光泽。碗置于深色木案之上，案面木纹细腻；案边一函线装古籍、一方素色绢布衬垫，一枝斜倚的白茉莉花枝，花朵细小洁白，与碗的暖黄轻声呼应。背景为大面积宣纸留白，米白色调，带淡淡纸纹肌理，顶部留白尤多，画面下方以极淡的墨色晕出一点阴影。光线柔和，来自左上方，如午后天光，暖而不烈。整体色彩克制：米白、宣纸色、浅灰、淡墨为基底，茉莉黄是唯一的主角。画面右上方以清雅小楷竖排题字"茉莉黄""黄釉瓷碗"，字形瘦劲含蓄。右下角自然融入一枚极小的淡金色手写签章"azrng"，形如古雅私印，旁可缀一枚极小朱红篆刻印章。禁止现代摄影棚产品图、玻璃展柜与巨大标题。

## 一色一物 · 图二《釉光深处·一眼看色》 → 03-02.png

竖版4:5局部特写构图，聚焦黄釉瓷碗的口沿与碗心，器物占据画面大部分，呈宋画小品式的细腻观察。画面重点表现釉色的层次变化：口沿釉薄处微微透亮，泛出浅淡的暖白；碗心积釉处颜色沉厚温润，转向淡赭的暖黄；侧光之下，釉面呈现从明亮的茉莉黄到蜜色、再到浅金色的细微渐变，亮处如蜡光流转，暗处安静含蓄，隐约可见修坯旋痕与釉水缓缓流淌的痕迹。光线自右侧斜入，明暗交界柔和，冷暖对比微妙：受光面偏暖黄，背光处隐约透出一点点灰调，让观者看见同一种黄在真实材质上的浓淡、冷暖与呼吸感。背景虚化为宣纸与绢的肌理，边缘以淡墨轻轻晕开，大量留白。左下角以小楷竖排题一句"黄中含暖，润而不艳"。右下角融入极小的淡金色手写签章"azrng"，形似古雅私印，低调自然。禁止现代纯色色块、高饱和滤镜与电商海报感。

## 一色一物 · 图三《明式书斋·一盏春色》 → 03-03.png

竖版4:5构图，明代文人书斋场景，古典透视，轻水墨国风插画，博物馆展签般的克制诗意。画面深处一架明式长窗，窗棂简洁疏朗，天光自窗格间透入，窗外隐约可见芭蕉叶影，随风轻晃。窗下木案上，本期黄釉瓷碗静静立着，碗旁一具小铜香炉、一只青瓷茶叶罐、一个小口瓷瓶中插着数朵白茉莉，与碗的暖黄彼此呼应，案角还搁着一卷半展的书册。案旁一把明式玫瑰椅，椅背上搭着素色衣衫；远处墙角立一架素面屏风，屏上大量留白。整体色调以米白、浅灰、淡墨为底，黄釉的茉莉黄与窗外一点蕉绿，是全画仅有的两处色彩。可添一位着明代素色衣裙的女子背影，立于案侧低头看碗，人物极小、不见面部特写，仅作环境点缀。光线安宁，微尘在光柱中可感。左上方竖排小楷题字"窑火收尽浓烈，留下一碗温柔"。右下角自然融入极小的淡金色手写签章"azrng"，另加一枚极小朱红篆刻印章。禁止现代建筑、现代人物与卡通元素。
