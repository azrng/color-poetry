# 琥珀黄 · 插画提示词

## 一色一诗 · 图一《兰陵夜宴·琥珀光》 → 01-01.png

竖版9:16中国古典水墨国风插画，呈现李白《客中行》"兰陵美酒郁金香，玉碗盛来琥珀光"的完整诗境。唐代客舍夜宴场景，深秋晴夜，暮色四合，室内烛火温润。前景近处一张深色木案，案上青玉碗盛满美酒，酒液自内透出琥珀黄（#FEBA07）的暖光，光晕柔和染亮案面与酒壶边缘，旁斜置一束郁金香花枝。中景一位唐代文士身着圆领宽袍，衣纹以淡墨勾勒，袖口染一线琥珀暖色，正举杯微醺而笑；对席主人执壶相劝，人物神态松快旷达，两者相对而坐，构成清晰的主客关系。远景以淡墨写意虚化客舍木窗与窗外夜色，窗棂间透出微微月色。整体轻水墨晕染，绢本质感，工笔细节与写意留白结合，前景清晰、中景柔和、远景淡雅，低饱和、安静雅致，留白约百分之三十，顶部约百分之十八保持简洁干净。画面右侧竖排行书题写"兰陵美酒郁金香，玉碗盛来琥珀光"，墨色有自然浓淡与飞白枯润变化，句末钤一枚极小朱红篆刻印章。右下角自然融入极小淡金色手写签章"azrng"，形如古雅私印，低调不突兀。

## 一色一诗 · 图二《玉碗盛来琥珀光》 → 01-02.png

竖版9:16中国古典水墨国风插画，聚焦《客中行》最核心的意象，一盏盛满琥珀光的玉碗，不出现人物。构图极简克制：画面中下部一只唐代青玉碗，碗壁温润通透，盛满的美酒自内而外透出琥珀黄（#FEBA07）的光，酒面微漾，一圈柔光如月晕般缓缓散开，映亮碗沿与案面一小片木纹。案头斜出一枝郁金香，花瓣沾一点暖金，花影以淡墨轻轻投在留白处。背景大面积留白，仅以极淡水墨晕染出夜的安静，一缕烛光自画面左上方斜斜落下，与碗中酒光遥遥呼应，让琥珀黄成为整幅画唯一的灵魂光源。整体绢本质感，玉碗与花枝以工笔细绘，背景以写意留白处理，留白约占百分之四十，低饱和、空灵雅致，顶部约百分之十八保持干净，为手机时间日期预留空间。画面左上竖排小楷题"玉碗盛来琥珀光"一句，墨色枯润相间、浓淡自然，句末钤一枚极小朱红篆刻印章。右下角自然融入极小的淡金色手写签章"azrng"，如古雅私印般低调融入画面。

## 一色一诗 · 图三《不知何处是他乡》 → 01-03.png

竖版9:16中国古典水墨国风插画，不复刻宴席场景，而是延伸《客中行》"不知何处是他乡"的旷达情绪。夜宴散后，微醺的唐代旅人独自立于客舍临水的木栏前，视角从侧后方远远望去：他宽袍缓带，一手负于身后，一手仍随意拎着酒壶，仰面向月，姿态松放自在，神态坦荡无碍。时值深秋晴夜，天际一轮满月以淡墨晕出清辉，星子疏落。栏下一江秋水静流，水面浮着碎金般的月影与灯影。他身旁廊下悬一盏灯笼，烛光透出琥珀黄（#FEBA07）的暖意，暖光染亮他的半幅衣袖与身边一截木栏，与清冷的月色夜空形成温柔的冷暖对照，他乡的夜，因这一点琥珀色而像家。整体轻水墨，绢本质感，近景人物工细，中景木栏柔和，远景江月写意淡雅，空间层层推远，留白约百分之三十五，顶部约百分之十八简洁干净。画面右侧竖排行书题"但使主人能醉客，不知何处是他乡"，墨色浓淡相宜，句末一枚极小朱红篆刻印章。右下角自然融入极小淡金色手写签章"azrng"，低调如私印。
