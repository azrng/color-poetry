# 赤金 · 插画提示词

## 一色一诗 · 图一《春江待月》 → 01-01.png

竖版9:16构图，春夜长江全景，中国古典轻水墨×精致国风插画风格，宣纸绢本质感，微见纤维肌理。画面顶部约五分之一保持洁净留白，为手机时间日期预留。中天悬一轮满月，工笔细线勾出月轮，月心以赤金轻轻晕染，如一面鎏金铜镜，清辉微暖。月色自右上方斜洒而下，江面以细劲的网巾纹波线层层铺开，波峰处以赤金淡淡扫染，滟滟随波，一路流向画面深处；远岸仅一痕淡墨远山，若隐若现。前景左下是一片江滩坡石，石旁生新芦细草，用工笔细写，苇叶向水微倾。坡上立一古装士人，唐代圆领长袍、束发头巾，侧身面向江月，双手拢于袖中，静立远望，神态安然、若有所待。人物衣缘、苇梢与波峰皆有一道极淡的赤金轮廓光。右侧上方以清雅行书竖排题写「不知江月待何人，但见长江送流水」，自右向左分列，墨色深润处见枯笔飞白，句末钤一枚极小朱红篆刻印章。右下角波纹间自然融入极小的淡金色手写签章「azrng」，形如古雅私印。整体低饱和，留白约三成，工笔与写意相融，宋画长卷意境，安静、克制、空灵。

## 一色一诗 · 图二《滟滟金波》 → 01-02.png

竖版9:16竖轴构图，极简意象特写，中国古典轻水墨×宋画小品意境，宣纸本，纸色微暖微斑驳。画面只保留两个元素：一轮孤月与一片江波。满月置于画面右上偏中，位置略高，月轮以细墨线勾勒，内以赤金晕染，边缘泛出柔和的暖金色光晕，微微向四周洇开，似在夜雾中悬停，像一句无人应答的等待。下方三分之二全为江水，水面以极细的平行波纹线水平铺陈，由近及远渐疏渐淡，波纹高光处以赤金轻点细染，如碎金浮动于墨线上，越近月下越暖，越远越退为淡墨与纸色，形成「月光在等、江水在流」的静默对望。不出现人物、舟船与岸石，无云无山，画面上下大量留白，留白约四成半，顶部近五分之一保持素净以置手机时间。左侧一列清雅小楷竖排题「不知江月待何人」，自上而下，墨色自然浓淡，带轻微飞白，句下钤一枚极小朱红篆印。右下角水面波线尽头，自然融入极小的淡金色手写签章「azrng」，如古雅私印，低调不夺目。整体低饱和、空灵雅致，强调赤金与月色本身。

## 一色一诗 · 图三《江楼望晓》 → 01-03.png

竖版9:16构图，情绪延伸之作，视角与时间均与图一图二明显不同：拂晓时分，西沉之月将落未落。中国古典轻水墨×精致国风插画风格，绢本设色。画面取自江畔小楼一角的凭栏视角：前景下方为一段深色木质栏杆与半掩的支摘窗，工笔细写木纹，栏杆上搭着一条素色披帛。一位唐代女子立于栏前，仅见背影，身着宽袖襦裙，发髻高绸，衣色以淡赭微染，身体微微前倾，凭栏远望江面，神情藏在背影之中，含着整夜的等待与将要落空的怅惘。画面中景为开阔的江水，自左向右缓缓流向天际，残月悬于左上天际，赤金色已淡，将尽未尽，最后一缕暖金洒在江面，随水波碎成粼粼细金，一路远去；一行孤雁自右上方掠过，雁影极小，正没入微亮的天光，喻「鸿雁长飞光不度」之意。远岸淡墨一痕，天色由赤金渐转鱼肚白。右侧以清雅行楷竖排题「但见长江送流水」，墨灰微润带枯笔，句末钤一枚极小朱红印章。右下角栏杆侧自然融入极小淡金色手写签章「azrng」。整体低饱和，留白约三成五，顶部素净，清寂而绵长。

## 一色一源 · 六格册页《赤金·鎏光小志》 → 02-01.png

最终整图提示词：一张竖版3:4中国风传统色博物插画，如一本古人留下的趣味颜色小册。米白宣纸、绢本肌理打底，整体低饱和淡墨基调，宋画小品笔意，工笔细节与写意晕染结合。画面由六个小场景散点竖排：其一，书斋一角，一枚小金锭被窗格斜光映出微红暖金光，小书生俯身细看，案上有香炉与书卷，竖排小字"赤金"；其二，老金铺掌柜持金铤在乌黑试金石上划出赤金色道痕，眯眼验色，小童踮脚偷看，柜上摆算盘与戥子；其三，蒙学堂教书先生指书页，页上竖排"白金、青金、赤金、黑金、黄金"，学童挠头疑惑；其四，鎏金作坊匠人以竹刀往铜炉上抹金泥，炭盆白雾袅袅，另一匠人举鎏金铜铃迎光而视，脸上映金；其五，老先生挥毫写"金无足赤"，学童歪头琢磨，夕照一线落于纸上；其六，远山落日晚霞如熔金流淌，山脚小庙屋脊一线鎏金，亭中文人凭栏远望。各场景间以淡墨云气、赤金色细线、梧桐枝叶与水纹自然串联，不用现代漫画格与粗边框，段落间大量留白呼吸。赤金色（#F2BE45）仅作点睛，分布于金锭、划痕、铜铃、字边与晚霞，克制呼应、绝不铺满。人物小巧生动，表情动作含趣不夸张。画面点缀少量竖排古风小字"赤金""金无足赤"。右下角融入一枚极小的淡金色手写体签章"azrng"，形如古雅私印，低调自然，无大字标题、无Logo水印、无现代元素。

第一格《赤金登场》：书案一角，一枚小金锭被窗格间斜进的夕光照亮，泛出微微偏红的暖金光；小书生俯身凑近细看，眼睛睁圆；案上另有素色香炉、半展书卷，旁书竖排小字"赤金"。配文：不是红，是微微泛红的暖金，一看就成色很足。

第二格《颜色验金》：老金铺内，掌柜将金铤在乌黑发亮的试金石上轻轻一划，划出深浅不同的金色道道，眯眼比对成色；柜边小童踮脚偷学，鼻尖快贴上石面；柜上散着算盘与戥子小秤。配文：老话说颜色越深、越偏赤黄，成色就越高。

第三格《前世是铜》：蒙学堂里，教书先生捋须指点书页，页上竖排写着五色金属之名"白金、青金、赤金、黑金、黄金"；一旁学童抓耳挠腮满脸疑惑，窗外一枝细竹。配文：有意思的是，《说文》时代，赤金原本指的还是铜。

第四格《炉火鎏金》：鎏金作坊中，匠人坐于炭火盆旁，以竹刀将金泥细细抹上一尊小铜炉，盆上白雾袅袅蒸腾；身后另一匠人举起刚鎏好的铜铃迎光细看，脸上映出一片暖金色。配文：金溶进水银抹上铜胎，火一烘，汞走了，金留下了。

第五格《足赤难求》：书斋内，老先生提笔在宣纸上写下"金无足赤"四字，搁笔微笑；小书童在旁歪头琢磨；一线夕照斜落纸上，字迹边缘泛起淡淡金光。配文："金无足赤，人无完人"——这颜色天生带点哲理。

第六格《落日熔金》：远景山水：落日熔金，晚霞自暖金渐入淡橙，云气如金液流淌；山脚小寺屋脊一线鎏金微闪；山亭中一位文人凭栏远望，衣带被晚风轻轻掀起。配文：李清照写"落日熔金"，原来天上也藏着赤金。
