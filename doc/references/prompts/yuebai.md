# 月白 · 插画提示词

## 一色一诗 · 图一《春江潮水连海平》 → 01-01.png

竖版9:16中国古典轻水墨国风插画，宋画意境，宣纸底色温润微黄。二月春夜，江潮涨满，天朗气清，一轮皎洁圆月自江海相接处缓缓升起，整片天空自上而下由墨青渐变为月白色，月白如轻纱铺展，使江与天在远处融为一体。前景右下两三枝低垂的白色花枝自画面外探入，花瓣敷染月白色泽，如蒙薄霜，暗合"月照花林皆似霰"；中景江面以细笔淡墨勾出层层潮纹，波光以极浅月白留白表现，一叶小小渔舟泊于江心，舟上人影极简，淡墨勾勒，披衣静坐仰面向月；远景山峦如眉，一抹淡墨隐入夜雾。留白约百分之三十五，顶部百分之十八保持虚净天空，为手机时间日期预留。右侧竖排清雅行书题"春江潮水连海平，海上明月共潮生"，墨色深润，带自然浓淡飞白，句末钤一枚极小朱红篆印。右下角极小淡金色手写体签章"azrng"，如古雅私印低调融入。整体低饱和，工笔与写意留白相融，空灵雅致，无任何现代元素。

## 一色一诗 · 图二《皎皎空中孤月轮》 → 01-02.png

竖版9:16中国古典水墨国风插画，绢本设色质感，构图极简，以孤月为唯一主角。夜空中一轮满月高悬于画面上三分之一处，月体并非刺目纯白，而以月白为基调，白中透出极淡的青蓝色，边缘晕开一圈朦胧月华，如宣纸上未干的水痕，缓缓洇入四周虚空。月旁一两缕薄云被月光照透，云脚以枯笔轻扫，若有似无。画面下三分之一仅以淡墨横扫出一线江面与沙汀的轮廓，白沙看不见——因为整片水岸已被月色染成模糊的月白，水与雾的界线渐渐消融，只余一道月光的倒影，细碎摇曳，自月轮正下方直落江心。不安排花木与人物，让"空"成为画面本身。留白超过百分之四十，顶部百分之二十为纯净月夜，适配手机时间日期。左侧竖排小楷题"江天一色无纤尘，皎皎空中孤月轮"，墨色由润转枯，富于变化，落款处钤一枚极小朱红篆印。右下角极小淡金色手写体签章"azrng"，古雅私印样式。低饱和、克制、空灵，如宋人小品，无现代元素。

## 一色一诗 · 图三《落月摇情满江树》 → 01-03.png

竖版9:16中国古典水墨国风插画，宣纸质感，情绪延伸之作，不复刻全景，而将视角沉至水面上方，从一叶小舟的侧后方望去。夜将尽，月已西斜，低低悬在画面左上方江树梢头，月轮比中天时清瘦，月白的光变得薄而凉，淡淡铺满无边江水。舟头独坐一位唐代旅人，宽袖长衫以淡墨勾勒、月白微微敷染，衣缘在夜色里泛着极浅的光，他侧身回望将落之月，姿态安静，神情含着一点未尽的怅惘与思念。船身四周水纹细密，碎月随波轻晃，仿佛满江树影与心事都被这一片月色摇动。中景空阔，只余一道月光倒影自远处斜斜连至舟边；远景岸树如烟，几枝江树垂入水中，剪影极淡。整幅以大面积月白与淡墨渲染长夜将尽的清寂，留白约百分之三十五，顶部百分之十五为虚静夜空。右上方竖排行书题"不知乘月几人归，落月摇情满江树"，墨色有浓淡枯润变化，钤一枚极小朱红篆印。右下角极小淡金色手写体签章"azrng"，自然融入。孤独、思念、清寂而不哀伤，东方诗意美学，无现代元素。

## 一色一源 · 六格册页《月白一夜》 → 02-01.png

最终整图提示词：一张竖版4:5的小红书知识插画，风格为中国古典轻水墨×宋画小品×古籍博物图鉴，整体像一册古人留下的颜色博物小志。宣纸与绢本肌理为底，米白、淡墨、浅灰构成基调，低饱和、色彩克制、大量留白。画面由六个小场景组成，不用粗黑边框，只以云气、梅枝、水纹与纸面留白自然衔接；一弯月亮的月相弧线从月牙到满月再归于淡月，统摄整图，串联场景推进。核心传统色为"月白"——极浅的淡蓝，近乎月光罩在白瓷上的青白之色，在画面中以色笺、古籍纸页、朝袍、裙裾、瓷釉、月光、衣衫等形式反复呼应，但绝不大面积铺满。场景一：文房案头，文人俯身指点展开色谱中的月白一格，窗外一弯淡月。场景二：油灯下有人执书夜读，摊开古籍上竖排小字"日赤，月白"，灯焰暖橘与月色清蓝相映。场景三：月坛夜祭，皇帝着月白朝袍对月行礼，长几上陈月白祭器，白描云纹。场景四：女子对铜镜理裙，油绿袄配月白裙，一深一浅。场景五：窑口旁匠人双手捧月白釉瓷碗，举向月亮眯眼比色。场景六：庭院中文人月白长衫立于夜风，广袖轻扬，梅枝斜出，人与月色融为一体。人物小巧生动，工笔细节与写意笔触结合，动作细腻带一丝趣味幽默，表情克制不夸张。画面点缀少量古风竖排文字与朱丝栏细线，水墨负责古意，月白负责记忆点。右下角留白处有一枚极小的淡金色手写体签章"azrng"，形如古雅私印，低调融入纸面，不做明显Logo，整图安静雅致、疏朗有呼吸感。

第一格《月白非白》：文房案头，一册展开的色谱小页平摊，靛青、月白、鱼肚白等色格依次排开。一位穿米白长衫的文人俯身，指尖正点在"月白"那一格上，微微挑眉，似有顿悟。窗外一弯淡月。配文：先说结论：月白不是白色，是往白里轻轻揉了一点蓝。

第二格《日赤月白》：夜读小景。一盏油灯，一函摊开的古籍，纸页上淡淡竖排小字"日赤，月白"。一人执灯细看，灯焰的暖橘与月色的清蓝在纸面悄悄对望。配文：《史记》早写明白了——"日赤，月白"，名字两千年前就报好了户口。

第三格《夕月礼》：月坛一角，夜空白描云纹烘托一轮圆月。一位皇帝身着月白朝袍，肃立对月行礼，长几上陈设月白色瓷质祭器，衣色与月色几乎融成一片。配文：秋分夜祭月，清代皇帝穿月白朝袍，连祭器都是全套月白。

第四格《绿袄月白裙》：闺房小景。明代女子立于铜镜前，低头理裙，油绿上袄配一条月白裙，一深一浅，镜中映出半身倒影。裙裾如一小片流动月光。配文：明朝小姐姐的穿搭笔记：油绿袄配月白裙，小说里都这么写。

第五格《窃月入窑》：窑口旁，匠人出窑后双手捧起一只月白釉瓷碗，举高对着天上月亮细细比色，眼睛眯起，那碗的釉色与月色难分彼此。缥色余瓷堆在脚边。配文：匠人举碗对月比色——这只月白釉，像把一片月光扣进了掌心。

第六格《一袖月光》：收尾大景。庭院中，文人着月白长衫立于夜风，广袖轻扬，远天淡月半隐梅枝之后。人、衣、月三者的颜色浑然一体，画面大面积留白。配文：它不喧哗，却是每个抬头望月的夜晚，最温柔的底色。

## 一色一物 · 图一《案头见月》 → 03-01.png

竖版4:5插画，中国古典轻水墨与精致国风插画结合，宋画小品式静物清供构图，博物馆藏品质感。画面以温润米白色宣纸为底，纸质纤维纹理隐约可见，上方三分之一大面积留白，以极淡的墨色晕出一角虚空，安静得像纸本身在呼吸。画面中下部，一只宋金时期钧窑月白釉瓶安放在深褐色老木案上：瓶为撇口、细长颈、溜肩、垂腹、圈足，造型端庄修长。通体施月白釉，乳浊失透，白中隐泛天青与淡蓝灰，釉面温润如凝脂，口沿、器身转折处釉薄而微透暖白，隐约可见细密开片，如冰面初裂。木案一侧置一函线装古籍与一只素雅小香炉，另一侧斜出一段疏淡梅枝剪影，皆以淡墨与浅淡设色轻轻带过，绝不喧宾夺主。光线为柔和的侧上方天光，在瓶身留下一道安静的月白高光，与留白处呼应。画面右侧竖排小楷题字"月白"，其下小字"钧窑月白釉瓶"，墨色清雅内敛。右下角一枚极小的淡金色手写签章"azrng"，形如古雅私印，旁可添一枚极小朱红篆刻印。整体色彩克制，以米白、宣纸色、浅灰、淡墨为基，月白釉色是全画灵魂，大量呼吸感，无任何现代元素。

## 一色一物 · 图二《月在釉中》 → 03-02.png

竖版4:5细节特写插画，延续中国古典轻水墨与精致国风风格，如同古画局部展开。画面主体为钧窑瓶口沿至肩腹的一处局部放大：观者的视线贴近釉面，焦点凝聚在方寸之间。乳浊月白釉在局部中呈现丰富的层次——釉厚处，青蓝色如薄云遮月，沉静含蓄；釉薄处，渐次过渡为米白与暖白，如晨雾未散；口沿线釉汁流淌处形成一道极细的淡青垂痕，转折棱线上光线轻轻一挑，泛起丝绢般柔和的光泽。釉中可见隐约的雾状乳光与冰裂般细密开片，纹路以极细淡墨勾勒，若有若无，如月下霜纹。背景为古籍纸色，浅灰纸纹细密，四周大面积留白，让釉色的呼吸空间充分。左下方以极淡的细墨线勾一只完整瓶形小样，如古器物图录中的线描示意，安静地呼应主体。画面右侧竖排一行清雅行楷小字："白中泛青，温润如月照薄云。"右下角融入极小的淡金色手写签章"azrng"，形如古雅私印，可配一枚极小朱红篆印。光影含蓄，明暗过渡柔和，冷暖对比极轻，无现代纯色色块，无现代元素，呈现体积、材质与时间的温度。

## 一色一物 · 图三《月夜书斋》 → 03-03.png

竖版4:5场景插画，中国古典轻水墨与国风插画结合，构建宋金时期文人书斋的月夜。整体色调以深夜的墨蓝灰、淡墨、宣纸米白构成，克制而安静，月白釉色成为夜色中唯一的光。画面上部，一轮满月悬在夜空，月光透过格子窗棂斜斜洒入书斋，在地面与文案上铺出一片清辉；窗外一角淡淡远山剪影，以湿笔淡墨轻扫。书斋中央的木案上，那只钧窑月白釉瓶静静立着，肩颈接了一枝吐蕊的素梅，釉面被月光与一盏将尽的小烛灯同时照着：烛光一侧微暖，月光一侧微青，正是月白"白中泛蓝、冷暖相生"的写照。案上另散置笔墨、一卷半开的书册、一方素砚。画面左侧远景处，一位着交领襕衫的文士凭案而坐，只留安静的侧影与背影，不刻画面部，姿态松弛，似在望月，亦似已入定，人物仅为环境中的点景。一道素色屏风立于一侧，仅以墨线与淡染示意。画面右上方竖排清雅行书小字："月光入釉，八百年犹有余温。"右下角极小的淡金色手写签章"azrng"，形如古雅私印，旁添一枚极小朱红篆印。整体留白充分，无现代建筑、无现代人物、无卡通与高饱和色彩，呈现夜的书斋、色的温度与古人的心境。
