# 青莲 · 插画提示词

## 一色一诗 · 图一《涧户无人》 → 01-01.png

竖版9:16手机壁纸，中国古典轻水墨宋画意境，宣纸绢本质感。早春清晨，微雨初歇，山中薄雾未散。远景：层叠淡青灰山影隐入雾中，仅以淡墨渍染出轮廓；中景：一道山涧自画面中部蜿蜒而下，溪水以留白与细墨波纹表现，涧畔一座极简茅屋柴门虚掩，屋内无人，一盏冷灶；近景：一株辛夷老树从左下斜出，虬枝苍劲，枝梢以工笔细勾，开满青莲色（#8B2671）花朵，花萼色深，瓣尖微淡，浓淡过渡自然，数枚花瓣正脱离枝头，飘向水面与青石。青莲色只落在花朵之上，如深山里唯一的声色。前景笔触清晰，中景柔和晕染，远景淡雅朦胧，空间层次分明。整幅留白约百分之四十，顶部五分之一保持雾天留白，为手机时间日期预留空间。画面右上起竖排小楷书法，自右至左书写「木末芙蓉花，山中发红萼。涧户寂无人，纷纷开且落」，墨色深墨，带自然浓淡与飞白枯润，诗首旁钤一枚极小朱红篆刻印章。右下角自然融入极小淡金色手写体签章azrng，形如古雅私印。低饱和、克制、空灵雅致，无人物、无现代元素。

## 一色一诗 · 图二《木末青莲》 → 01-02.png

竖版9:16手机壁纸，中国古典轻水墨与精致国风插画结合，绢本设色质感，构图极简，上密下疏。早春正午，天光清透，无风。主体只有一枝辛夷：老枝自画面右上方斜垂而入，枝干以枯笔淡墨写出，苍劲有节，转折处见笔意；枝末梢开三朵青莲色（#8B2671）玉兰花，一朵全开，花瓣以工笔层层晕染，颜色自瓣心向外由深渐淡；一朵半开侧向，含蓄收敛；另有一枚紧致花苞以深色萼片包裹。花下留出大面积空白宣纸，整幅留白约百分之四十五；画面下方仅以一痕极淡的墨色水影示意山涧，一枚脱离的花瓣悬停半空，将落未落，是全画唯一的动势。青莲色集中于三朵花与落瓣之上，成为视觉重心，绝不铺陈为背景。顶部五分之一完全留白，安静简洁，为手机时间日期预留。画面左侧竖排行书两列，自右至左书写「木末芙蓉花，山中发红萼」，墨色墨灰为主，带自然枯润变化，句末钤一枚极小朱红印章。右下角以极小淡金色手写体azrng作签，低调如古雅私印。低饱和、空灵，无人物、无现代元素。

## 一色一诗 · 图三《一瓣随涧去》 → 01-03.png

竖版9:16手机壁纸，中国古典轻水墨，绢本质感，为《辛夷坞》的情绪延伸之作。时间改为暮色四合的黄昏，雨后初晴，视角极低，几乎贴着涧水水面。前景：占画面下方三分之一的溪涧水面，墨线勾出细密涟漪，一枚青莲色（#8B2671）落瓣漂在水心，随水波轻轻荡开一圈微光，花色沉稳内敛，映着暮天微亮；水面倒影里隐约可见一枝已谢的辛夷枝影，暗示花事已尽。中景：对岸几块淡墨山石，湿笔晕染，边缘朦胧。远景：山影融入带青莲紫红色调的暮霭之中，天光自山脊后透出一点微暖，整片远景以极淡的青莲色由深至浅层层渍染，是全画唯一成片的青莲色，安静而微微怅然，替「纷纷开且落」收束余绪。整幅留白约百分之三十五，顶部五分之一为渐空的暮色天际，为手机时间日期留白。画面右上角竖排小楷一列，自右至左书写「纷纷开且落」五字，墨色深墨，收笔微枯，旁钤一枚极小朱红篆印。右下角自然融入极小淡金色手写体签章azrng。低饱和、清寂含蓄，无人而情自见，无任何现代元素。

## 一色一源 · 六格册页《一色青莲》 → 02-01.png

最终整图提示词：一张竖版 3:4 的中国古风知识插画，宣纸与绢本肌理，米白底色，整体如一册宋人博物小册页，由六个散点小场景组成，以淡淡的荷梗、水纹与云气细线自然衔接，无粗黑边框，留白充足。核心传统色为青莲色（蓝中泛紫红，参考色值 #8B2671），全图低饱和水墨晕染，淡墨、米白、浅灰打底。

场景一：晨雾荷塘，一朵青莲色莲花半开，花瓣尖深紫、根部偏蓝白，蜻蜓悬停，小童蹲在岸边探头看花。场景二：文人书案，文人对着莲瓣与色碟提笔沉思，纸上竖排小楷"青""莲"二字，案角叠着青莲色色笺。场景三：山寺一角，佛像低眉坐于莲座，云气缭绕，袈裟一角青莲色晕染，座边开小朵青莲。场景四：月下江畔，白衣诗人李白举杯望月，衣带当风，江水映出青莲色莲影。场景五：染坊晾布架，老染匠举起新染的青莲色布对光眯眼比色，小童踮脚偷摸布角，染缸冒热气。场景六：雨后暮色荷塘，水珠滚于荷叶，一朵青莲亭亭不染，岸石上搁斗笠竹杖，人已远去，留白渐多。

色彩克制，青莲色只在莲花、色笺、袈裟一角、布匹与江中莲影等处点睛呼应，不大面积铺满。人物小巧生动，工笔与写意结合，动作细微带一点幽默。每格旁配少量竖排小楷古风文字，如"心如世上青莲色""不染"。右下角一枚极小的淡金色手写签章"azrng"，形如古雅私印，低调融入宣纸。

第一格《莲开一色》：晨雾荷塘一角，一朵青莲色莲花半开，花瓣尖部色深、根部偏蓝白，花瓣上停一只蜻蜓；淡墨荷叶斜出，岸边一个小童蹲着探头看花，看得入神。配文：今日主角青莲色——紫里带蓝的那种，像一朵开在晨雾里的莲。

第二格《青是蓝的》：文人书案一角，一位文人对着案上莲瓣与几只色碟提笔沉思，纸上竖排小楷"青""莲"二字，案角叠着几张青莲色色笺。配文：古人起名很讲究：青是蓝，莲是紫红，蓝打底，紫红添一点韵。

第三格《佛眼如莲》：山寺一角，佛像低眉垂目，坐于莲座，身后云气缭绕，袈裟一角以青莲色轻轻晕染，莲座旁开一小朵青莲。配文：佛经夸眼睛好看，会写"目净修广如青莲"，澄澈又干净。

第四格《青莲居士》：月下江畔，白衣诗人李白举杯望月，衣带当风，身旁石上搁一卷诗稿，江水中映出一朵青莲色莲影。配文：李白自号"青莲居士"，还写过"心如世上青莲色"。

第五格《染坊比色》：染坊晾布架下，两口染缸冒热气，老染匠举着一段刚染好的青莲色布对着天光眯眼比对，小童踮脚偷偷想摸布角。配文：染坊老师傅都懂：红蓝对拼不像话，得一层层套染。

第六格《不染之心》：雨后荷塘暮色，水珠在荷叶上滚动，一朵青莲亭亭而立，微尘不沾；岸石上搁着一顶斗笠与一根竹杖，人已远去，只余一抹青莲。配文：谐音"清廉"，出淤泥而不染——古人爱的是它的品格。
